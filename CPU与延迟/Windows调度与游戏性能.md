# Windows 调度与游戏性能

## CPU 调度

Windows 会根据前台程序、后台任务、响应性和系统策略分配 CPU 时间。

游戏优化通常关注：

- 前台程序响应速度
- 调度延迟
- 后台任务占用
- 多媒体任务优先级

## Win32PrioritySeparation

该设置影响 Windows 对前台程序和后台任务的 CPU 时间分配策略。

它不是简单的“性能开关”，实际效果取决于：

- CPU 架构
- 游戏引擎
- 后台程序数量
- Windows 版本

## tweakbyjie 对应项目

`tweakbyjie` 中的 CPU 调度相关调整属于系统行为优化，应结合实际游戏测试。

建议关注：

- 帧时间稳定性
- 输入延迟
- 后台负载
- 游戏实际表现

## 原则

优化目标不是让某一个指标最大，而是在稳定性和响应速度之间取得平衡。
