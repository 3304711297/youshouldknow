# 删除「此电脑」中多余软件快捷方式图标

> **分类**：系统知识 · 系统设置
>
> **适用场景**：安装网盘等软件后，「此电脑」窗口的「设备和驱动器」区域多出一些快捷方式图标（如百度网盘、迅雷、WPS 网盘等），影响观感且无法直接删除，本文介绍通过注册表清理的方法。
>
> 本文方法已对照多个独立技术社区信源交叉验证，核查记录见文末。

---

## 问题背景

部分国产软件（网盘类尤其常见）安装后会在「此电脑 → 设备和驱动器」区域注册自己的快捷方式图标。这类图标不是普通文件，右键没有删除选项，需要到注册表中删除其命名空间注册项。

## 操作步骤

**第 1 步：打开注册表编辑器**

按 `Win + R` 打开运行框，输入 `regedit` 回车。

**第 2 步：定位到命名空间注册项**

在注册表编辑器地址栏粘贴以下路径并回车：

```text
计算机\HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\NameSpace
```

**第 3 步：找到并删除对应软件的项**

`NameSpace` 下有若干以 GUID 命名的子项。逐个点击子项，右侧窗格会显示对应的软件 / 驱动器名称——找到要删除的图标对应的子项，右键 → 删除。

**第 4 步：重启资源管理器生效**

删除后重启资源管理器（任务管理器中结束 `Windows 资源管理器` 后重新运行）或重启电脑，图标即消失。

## 注意事项

1. **操作前务必备份**：右键点击 `NameSpace` 项 → 「导出」，将 `.reg` 文件保存到桌面；如需恢复，双击该文件导入即可；
2. 必须删除**整个子项**，仅修改项内的数据不会生效；
3. 「此电脑」中的系统自带文件夹（文档、下载、图片等）不受此路径影响，可放心操作；
4. 若在 `HKEY_CURRENT_USER` 路径下找不到对应图标，部分软件注册在计算机级路径下，需以管理员身份打开注册表编辑器后检查：

   ```text
   计算机\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\MyComputer\NameSpace
   ```

5. 删除注册项只是移除图标入口，不影响软件本体及其正常使用；软件大版本更新后可能会重新注册图标，届时按同样方法再删一次即可。

| 声明 | 核查结果 |
| --- | --- |
| 图标注册于 `HKCU\...\Explorer\MyComputer\NameSpace`，删除子项即可移除图标 | ✅ 属实：CSDN、知乎、HP 社区、B 站专栏等多信源记载的同一标准方法，Win10/Win11 通用 |
| 点击子项时右侧窗格显示对应软件名称 | ✅ 属实：社区教程均以此方式辨认 GUID 对应的软件 |
| 仅改数据无效，需删除整个项 | ✅ 属实：社区实测结论一致 |
| 部分软件注册在 HKLM 同名路径（需管理员权限） | ✅ 属实：多个教程补充说明 HKCU/HKLM 两处均需检查 |
