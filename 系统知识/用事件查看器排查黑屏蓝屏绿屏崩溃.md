# 用事件查看器排查黑屏、蓝屏、绿屏崩溃

> **分类**：系统知识 · 故障排查
>
> **适用场景**：电脑突然黑屏后自动重启（系统崩溃，不是死机）、蓝屏（BSOD）、绿屏（Windows 预览版系统的「蓝屏」）之后，用事件查看器定位崩溃记录与原因。
>
> 本文方法已对照微软官方文档核实，核查记录见文末。

---

## 一、先分清三种情况

| 现象 | 本质 |
| --- | --- |
| 黑屏后自动重启 | 系统崩溃的一种——显示子系统一并崩溃（或来不及绘制蓝屏界面），机器自己重启了，**不是死机** |
| 蓝屏（BSOD） | 系统遇到致命错误停止运行并显示停止代码界面，随后自动重启 |
| 绿屏（GSOD） | Windows **预览体验版（Insider Preview）**专用——预览版系统把蓝屏界面换成了绿色背景，本质与蓝屏相同 |

三种情况的崩溃记录都写入同一个位置：**事件查看器的系统日志**。所以排查方法一致。

## 二、筛选崩溃记录

1. 右键「开始」→「事件查看器」（或右键「此电脑」→「管理」→「事件查看器」）；
2. 依次展开 **Windows 日志 → 系统**；
3. 点击右侧 **「筛选当前日志」**；
4. 在「事件级别」中勾选 **关键（Critical）** 和 **错误（Error）**，确定。

> 关键 / 错误事件是系统在无法自行恢复时记录的，用于帮助识别故障原因。在列表中它们分别以**红色叹号**和**黄色叹号**标识。

崩溃发生后，按时间排序找到重启前后的一段记录即可。

## 三、认识两个关键事件

**1. Kernel-Power，事件 ID 41（级别：错误）**

> 系统已重新启动，而系统未先正常关机。若系统停止响应、崩溃或意外断电，就会记录此事件。

注意：**它是「症状」不是「原因」**——意外断电、死机、系统崩溃都会留下这条记录。它的价值在于提示你：去看它**时间之前**的关键事件或 BugCheck 1001 事件，那才是真正的线索。

**2. BugCheck，事件 ID 1001（来源：BugCheck）**

> 计算机已从检测到 bug 的错误中重新启动。

这条记录只在**系统真正蓝屏 / 绿屏崩溃**时出现，说明里包含**停止代码**（形如 `0x00000139` 的十六进制数值）和内存转储文件路径——诊断价值最高。

## 四、诊断分流

| 组合 | 结论 | 下一步 |
| --- | --- | --- |
| 41 + **有** 1001 | 系统崩溃（蓝屏 / 绿屏 / 黑屏崩溃都算） | 记下 1001 里的停止代码，查该代码含义（微软官方停止代码文档）；需要深挖时用 WinDbg 分析 `C:\Windows\Minidump` 下的转储文件 |
| 41 + **无** 1001 | 系统没有崩溃记录却意外重启，多为**供电 / 硬件层面**问题 | 检查电源功率与线缆、温度（过热保护）、超频设置（CPU/内存/显卡降压超频不稳是常见原因）、市电环境 |

补充排查点：

- 筛选结果里留意 **WHEA-Logger** 来源的事件（硬件报告的错误，如 CPU / 总线问题），常与不稳定超频相关；
- 频繁黑屏（还能听到声音、主机仍在运行）则更像**显卡驱动崩溃**而非系统崩溃，去看「系统」日志中的 `Display`（显示驱动 nvlddmkm / amdwddmg 超时重置）事件；
- 蓝屏界面上直接显示的二维码和停止代码（如 `CRITICAL_PROCESS_DIED`）与 1001 事件中的代码是对应的。

## 五、常用入口备忘

| 操作 | 路径 |
| --- | --- |
| 事件查看器 | `Win + R` → `eventvwr.msc` |
| 系统崩溃日志 | Windows 日志 → 系统（筛选关键 / 错误） |
| 蓝屏转储文件 | `C:\Windows\Minidump\`（小转储） |
| 微软官方 Event 41 排障指南 | 见文末参考来源 |

## 事实核查记录

| 声明 | 核查结果 |
| --- | --- |
| Kernel-Power 41 = 系统未正常关机就重启；死机、崩溃、意外断电都会记录；应查看其之前的关键事件或 BugCheck 1001 | ✅ 属实：事件说明文字与微软官方排障文档（Event ID 41）一致 |
| BugCheck 1001 = 系统从 bugcheck 崩溃中重启，含停止代码与转储信息 | ✅ 属实：微软官方问答与社区案例一致 |
| 41 无 1001 伴随 → 指向供电 / 硬件类问题而非系统崩溃 | ✅ 属实：微软官方排障文档与社区诊断经验一致 |
| 事件查看器筛选：系统日志 → 筛选当前日志 → 勾选关键 / 错误 | ✅ 属实：标准操作流程；关键 / 错误以红 / 黄叹号标识 |
| 预览版系统蓝屏为绿色（绿屏 GSOD） | ✅ 属实：Windows 预览体验版自 Win10 起 BugCheck 界面使用绿色背景，为微软预览版专属标识 |
| 黑屏自动重启也属系统崩溃（非死机），日志同样有 41 / 1001 记录 | ✅ 属实：显示子系统崩溃或来不及绘制时表现为黑屏，内核侧仍是 bugcheck 流程 |
