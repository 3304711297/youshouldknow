# Windows 优化前准备与风险等级规范

## 风险等级

后续系统优化文章统一参考以下等级：

### 🟢 推荐

普通设置调整，通常不会影响系统核心功能。

### 🟡 谨慎

可能影响部分 Windows 功能，需要了解作用后再修改。

### 🔴 高风险

涉及注册表、系统组件、驱动、安全机制等核心区域，修改前建议备份。

## 优化前准备

进行系统优化前建议：

1. 创建系统还原点。
2. 备份重要文件。
3. 记录当前 BIOS 设置。
4. 记录当前驱动版本。
5. 对注册表修改前导出对应项。
6. 记录修改内容，方便恢复。

## 原则

优化不是修改越多越好。

正确方式：

- 了解功能作用；
- 根据硬件和使用场景选择；
- 修改后测试实际效果；
- 保留恢复方案。

性能优化应优先考虑稳定性。
