## 与其他分类的边界

- `内存与存储/`：Windows 内存管理（压缩/Prefetch/页面文件）与 NVMe 原理；`内存超频/` 是独立的硬件超频专题，不属于系统设置优化。
- `BIOS与固件/`：固件刷写与恢复风险；超频涉及 BIOS 时序与电压，需单独评估稳定性与保修影响。
