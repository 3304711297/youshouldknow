# 电源计划创建与优化：powercfg 与 Power Settings Explorer 使用指南

> **分类**：系统知识 · 电源管理
>
> **适用场景**：创建并深度定制 Windows 电源计划（解锁被隐藏的电源设置），并用组策略锁定，防止系统或软件擅自切换计划。Win10 / Win11 通用。
>
> 本文方法已对照微软官方文档、组策略参考与工具官方帖子交叉验证，核查记录见文末。

---

## 说在前头：AC 与 DC

电源计划中**每个设置都有两套值**：

- **AC** = 插电状态（交流电，Adapter Connected）；
- **DC** = 非插电 / 电池状态（Direct Current）。

笔记本优化时两套值都要看：常见做法是插电时放开性能、电池时收紧省电；也可按需把两套设为相同值。Windows 11 中电源模式滑块（最佳能效~最佳性能）与经典电源计划是并存关系，锁定计划可避免滑块联动带来的干扰。

## 电源调优原则与睡眠排障

电源计划会影响处理器调度、设备省电策略、温度、续航和系统响应。不存在适合所有机器的“最高性能”方案：

- 游戏设备可关注响应延迟和频率稳定性；
- 笔记本电池模式应关注续航、温度和噪音；
- 工作设备应优先稳定、休眠和外设兼容性；
- 修改前检测当前计划、记录原始 GUID 和导出备份；
- 应用后检查 `powercfg /getactivescheme`、温度、功耗、睡眠/唤醒和实际负载；
- 不要同时修改电源计划、BIOS、驱动和 CPU 调度参数。

### 无法自动睡眠与意外唤醒

这是两个不同问题：

| 现象 | 首要命令 |
|---|---|
| 到时间不睡眠 | `powercfg /requests` |
| 睡着后自行唤醒 | `powercfg /lastwake`、`powercfg /waketimers` |

管理员终端可进一步使用：

```bat
powercfg /systemsleepdiagnostics
powercfg /devicequery wake_armed
```

`/requests` 会列出 DISPLAY、SYSTEM、AWAYMODE、PERF 等阻止睡眠的应用或驱动请求；Power-Troubleshooter 事件日志主要用于查看已发生的睡眠/唤醒转换和唤醒源。排查时优先关闭具体软件的“阻止休眠/离开模式”设置，或更新显卡、网卡和芯片组驱动，不要直接关闭所有电源功能。

详细睡眠、休眠、混合睡眠原理仍见：[Windows 睡眠、休眠与混合睡眠详解](./Windows-睡眠-休眠与混合睡眠详解.md)。

## 一、懒人方案：直接应用现成的超性能电源计划（可选）

不想逐项手动调校的读者，可以直接使用本项目作者维护的**超性能电源计划**（位于另一个项目 [tweakbyjie](https://github.com/3304711297/tweakbyjie)）：基于高性能模板深度调校，共 **177 项设置**——CPU 全程满频，硬盘 / NVMe / 无线网卡 / USB 全链路不节电，永不自动睡眠等。全部设置项的明细表见该项目的 [OPTIMIZATION-DETAILS.md](https://github.com/3304711297/tweakbyjie/blob/main/docs/reference/OPTIMIZATION-DETAILS.md)，本文不再罗列。

**应用方式 A：一键脚本（推荐）**

运行 tweakbyjie 项目的 `tweakbyjie.ps1`，选择**选项 7**（超性能电源计划）：

- 子选项 1：自动先把当前正在使用的电源计划备份为 `power-backup.pow`，再导入并应用超性能计划；
- 子选项 2：随时把备份的计划恢复回来。

自动备份当前活动计划并应用；可按快照恢复活动电源计划，无需手动敲命令。这里的恢复不覆盖其他系统策略、组策略或用户之后对计划做的修改。

**应用方式 B：手动命令**

从 [tweakbyjie 仓库](https://github.com/3304711297/tweakbyjie) 下载 `ultimate-performance.pow`，以管理员身份运行：

```bat
:: 1. 备份当前计划（推荐）
powercfg /getactivescheme
powercfg /export power-backup.pow 当前计划GUID

:: 2. 导入超性能计划（自动生成新 GUID）
powercfg /import ultimate-performance.pow

:: 3. 查看新导入计划的 GUID（列表末尾新增项）
powercfg /list

:: 4. 应用
powercfg /setactive 新计划GUID
```

**注意事项**：

- 该计划交流 / 直流两套值均为性能优先，**笔记本用电池时续航会明显缩短、发热增加**，更适合台式机或长期插电场景；
- 可恢复活动电源计划快照：用 `/import power-backup.pow` 恢复备份，或 `/setactive` 切回内置平衡方案；这不等于整个系统电源策略的完全回滚。

## 二、创建电源计划

**图形界面**：控制面板 → 硬件和声音 → 电源选项 → 左侧「创建电源计划」→ 选择模板（平衡/高性能/节能）→ 命名完成。

**命令行**（从现有方案复制，适合脚本化）：

```bat
powercfg -duplicatescheme 381b4222-f694-41f0-9685-ff5bb260df2e
powercfg /renamename <新GUID> 新方案名
⚠️ 勘误（2026-09-12 Win11 26200 实测 EXIT=1）：/duplicatescheme 的官方语法**不含名称参数**，复制后需用 /renamename 或 powercfg /setactive 前先重命名
```

常用内置方案 GUID：

| 方案 | GUID |
| --- | --- |
| 平衡（Balanced） | `381b4222-f694-41f0-9685-ff5bb260df2e` |
| 高性能（High Performance） | `8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c` |
| 节能（Power Saver） | `a1841308-3541-4fab-bc81-f71556f20b4a` |

> 电源计划本质是注册表中的方案数据库，可用 `powercfg /export 备份.pow GUID` 导出、`powercfg /import 备份.pow` 在其他机器导入，迁移配置非常方便。

## 三、优化电源计划：Power Settings Explorer

控制面板 / 设置里露出的电源选项只是冰山一角——大量设置（处理器电源管理策略、内核闲置、各种超时与策略）被系统或 OEM 通过注册表标记为**隐藏**。**Power Settings Explorer**（Guru3D 论坛用户 mbk1969 开发的免费小工具，.NET 4.5 运行）可以把它们全部列出来直接编辑：

- 列出当前方案**全部**电源设置，包括被隐藏的；
- 直接修改每个设置的 AC / DC 两个值；
- 隐藏 / 取消隐藏任意设置项。

使用要点：

1. 从官方帖子内的 MediaFire 链接下载（仅一个 exe，免安装），**以管理员身份运行**；
2. 顶部选择要编辑的电源计划，列表中点选设置项，右侧分别填入 AC / DC 当前值与最小/最大值范围内的新值；
3. 修改即时写入当前计划；不想暴露给别人的设置可重新设为隐藏。

> 需要图形化大量调整隐藏项时用本工具最顺手；只改个别项也可以用 `powercfg /setacvalueindex` / `setdcvalueindex`（设置 AC/DC 值）+ `powercfg /setactive` 刷新生效的命令行方式，具体命令见文末参考教程。

## 四、PowerSettings 里的 `ValueMin` / `ValueMax` 不是"当前值"

社区教程里有一条流传很广的说法：把电源子组下某些 GUID 的 `ValueMin` 和 `ValueMax` 都改成 `100`，"就能阻止游戏/软件改动电源计划"。这个做法基于对注册表结构的误解：

```text
HKLM\SYSTEM\CurrentControlSet\Control\Power\PowerSettings\<子组GUID>\<设置GUID>
├─ （默认值）        : 友好名 / 描述的间接字符串
├─ Attributes       : 决定该项是否在界面隐藏（1=隐藏，2=显示）
├─ ValueIncrement   : 允许取值的步长
├─ ValueMax         : 允许取值的**上限**
└─ ValueMin         : 允许取值的**下限**
```

关键区别：

- 这里存的是**该设置项允许的取值范围元数据**（界面输入框的上下限），不是当前电源计划实际套用的值；
- 当前值存放在同一子组下的**方案实例键**（按方案 GUID 分区）里，通过 `powercfg /query` 或 `PowerWriteACValueIndex` 一类 API 读写；
- 把 `ValueMin`/`ValueMax` 都改成 `100`，只是把"这个参数只允许是 100"这一约束写进元数据，**不能阻止**任何程序调用电源 API 写入其他值——API 校验所用的是内核侧的定义，改注册表元数据并不构成权限或策略层面的拦截；
- 实测佐证（2026-09-13，Windows 11 26200）：`0cc5b647-c1df-4637-891a-dec35c318583` 与 `...584` 两项的 `ValueMin=0` / `ValueMax=100` / `ValueIncrement=1`，`FriendlyName` 为"处理器性能核心放置最小核心数量"（含 Power Efficiency Class 1 版本）。这两项控制的是**核心停放（Core Parking）**，与"性能提升模式"无关。

### 相关 GUID 勘误

`be337238-0d82-4166-a960-4f3749d470c7` 是社区教程中常见的"处理器性能提升模式"写法，但**该 GUID 在系统上不存在**（`powercfg /query` 返回"指定的电源方案、子组或设置不存在"）。正确值为：

```text
be337238-0d82-4146-a960-4f3749d470c7   (PERFBOOSTMODE，处理器性能提升模式)
```

两者只差第三段的 `4166` / `4146`。照抄错误 GUID 的脚本不会报错退出，但什么都没改到——排查时会误判为"设置被游戏改回去了"。本机实测（Windows 11 26200）：错误 GUID 报不存在，正确 GUID 返回可选项 `000` 已禁用 / `001` 已启用 / `002` 积极 / `003` 激进。

> 若目标是"防止游戏篡改电源计划"，正确路径是检测 + 恢复（`powercfg /query` 对比基线、导出 `.pow` 备份、用组策略锁定活动方案），详见[游戏篡改电源计划的检测与恢复](./游戏篡改电源计划的检测与恢复.md)。

## 五、锁定电源计划：本地组策略编辑器

防止系统按场景自动切换计划（或他人误改），可用组策略把自定义方案锁定为唯一活动方案：

1. `Win + R` → 输入 `gpedit.msc` 打开本地组策略编辑器；
2. 依次展开：

   ```text
   计算机配置 → 管理模板 → 系统 → 电源管理
   ```

3. 双击「**指定自定义活动电源方案**」，选择「已启用」；
4. 填入目标电源计划的 GUID——在命令提示符运行以下命令即可看到每个方案对应的 GUID：

   ```bat
   powercfg /list
   ```

5. 应用后，系统将被强制锁定在该计划，电源模式滑块与控制面板的切换操作失效。

> 📌 注意事项：
> - 该策略只**锁定激活的方案**，不会创建或导入方案——请确保目标计划已在本机存在；
> - 组策略编辑器仅专业版 / 企业版 / 教育版自带，家庭版可通过注册表等效设置：在 `HKLM\SOFTWARE\Policies\Microsoft\Power\PowerSettings` 下新建字符串值 `ActivePowerScheme`，数据填方案 GUID，重启生效；
> - 解锁方法：将策略改回「未配置」并刷新组策略（`gpupdate /force`）或删除上述注册表值。

## 附：常用 powercfg 命令速查

均需管理员权限的命令提示符执行：

| 命令 | 作用 |
| --- | --- |
| `powercfg /list` | 列出所有电源方案及 GUID（`*` 为当前活动方案） |
| `powercfg /setactive GUID` | 切换活动方案 |
| `powercfg /query GUID 子组 子设置` | 查询方案设置的当前值与可用值 |
| `powercfg /setacvalueindex` / `setdcvalueindex` | 设置某项的 AC / DC 值 |
| `powercfg -duplicatescheme GUID`（复制）+ `/renamename GUID 新名`（重命名） | 复制方案 |
| `powercfg /export 文件.pow GUID` / `/import` | 导出 / 导入方案 |
| `powercfg /batteryreport` | 生成电池健康报告 |
| `powercfg /energy` | 生成能耗诊断报告 |
