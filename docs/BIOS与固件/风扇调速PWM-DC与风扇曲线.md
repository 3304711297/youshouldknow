# 风扇调速 PWM/DC 与风扇曲线

> **分类**：BIOS 与固件 · 性能优化项
>
> **一句话**：4 针选 PWM、3 针选 DC、水泵走泵口恒速——模式设反是"风扇狂转/不转"的第一大原因；曲线背后还有温度源、防抖延迟、起停三个隐藏主角。

## PWM 与 DC 的本质区别

| 模式 | 针脚 | 原理 | 特点 |
|---|---|---|---|
| PWM（脉宽调制） | 4 针 | 第 4 针发约 25kHz 方波信号控制转速，供电恒定 12V | 低速可控仍有启动扭矩、灯效稳 |
| DC（电压/降压调速） | 3 针 | 主板调供电电压（12V 满速，5~7V 附近启动电压下限） | 电压太低会停转、带灯风扇灯不亮 |

- 买风扇坚决选 4 针；线序：黑=地线、红=12V、黄/白=转速检测、蓝=第 4 针 PWM。
- **3 针风扇误设 PWM 模式**：主板检测不到转速信号、以为 0 转而一直给满压——这是风扇狂转的最常见原因；**4 针风扇设 DC 模式**则低速可能停转或抖动。
- 转接线/集线器注意：4 转 3 转接线会让 PWM 调速悬空；一分二集线器把两风扇转速检测并联可能骗过主板。

## 接口与水泵

- 接口标注：CPU_FAN、SYS_FAN、AIO_PUMP/W_PUMP+；普通风扇口供电上限约 1A（12W），泵口约 2A（24W）或更高；
- **水泵设置死线**：设满速或恒定转速，绝不允许随温度调低——DC 模式低电压下水流量急剧衰减、水泵寿命受损，散热崩盘 CPU 过热。普通风扇插泵口会永远满转（吵），水泵插普通口供电不足（危险）。

## 风扇曲线三个隐藏主角

1. **温度源**：CPU 风扇跟 CPU 温度；机箱风扇跟主板/VRM 温度（CPU 温度瞬时波动会让机箱风扇"喘气"）；高端主板支持多温度源取最高值。
2. **防抖延迟**：加速（Step Up）推荐 0.1~0.3 秒、减速（Step Down）0.3~0.7 秒——宁可多吹几秒，也别频繁升降吵人。
3. **起停（0 RPM/Stop）**：低于阈值彻底停转零分贝。**大坑：只有纯 4 针 PWM 风扇能被稳定唤醒**——DC 模式风扇停转后主板可能唤不醒；CPU 塔扇和一体水冷泵严禁开停转（过热降频甚至关机保护），机箱排扇可以开。

## 实战曲线参考

- 典型工作区：约 45 度维持低速待机 → 约 65 度爬升 → 85 度拉到 85~95% 全力保散热，别为静音强拉过低转速；
- 最低转速参考：PWM 模式约 20% 起步，DC 模式约 60% 起步（电压再低压不起来）；
- 温度超约 85 度主板会强制拉高转速，这是保护机制，不该改；
- 品牌入口：华硕 Q-Fan Configuration（CPU/机箱风扇分开两个条目）、微星 Hardware Monitor 逐接口设置、技嘉 Smart Fan 6 可视化拖点最好用。

## 常见坑清单

1. 3 针风扇设成 PWM → 狂转；
2. 4 针风扇插 3 针口 → 只剩 DC 调速；
3. 水泵插普通口/设了温控 → 散热崩盘；
4. CPU 风扇插机箱口 → 开机报 CPU Fan Error 按 F1 才能进（改回 CPU_FAN 口，或在监控页把转速下限调低——如猫头鹰风扇最低约 200 转低于主板默认 600 转阈值会误报）；
5. 温度源选错 → 调速完全无效；
6. 清 CMOS 后风扇策略被重置 → 变吵不是风扇坏了，重新拉曲线；
7. 只看百分比不看实际转速 → 2000 转工业扇 50% 已 1000 转，耳朵才是最终标准。

## BIOS 与系统软件双保险

BIOS 调速保底（不依赖系统，但只有 3~5 个控制点、单一温度源）；系统侧可配开源免费的 Fan Control（任意多点曲线、多温度源取最高、分组控制）。厂商全家桶后台占用大、偶发冲突，不值得为风扇装。
