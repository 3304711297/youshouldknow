# 厂商软件自动安装开关

> **分类**：BIOS 与固件 · 厂商全家桶治理
>
> **一句话**：主板 BIOS 里藏着一个"自动安装厂商软件"开关，每次开机往系统塞全家桶（Armoury Crate、MSI Center、APP Center）；在 Windows 里点"否"只是临时拒绝，进 BIOS 关掉开关才一劳永逸。

## 原理

开机自检完成后、Windows 启动之前，UEFI 向 ACPI 表写入一个软件安装任务标记（符合规范、非病毒的合法操作）。Windows 启动读取 ACPI 表识别任务后走两条路径：

1. 弹窗询问是否安装——点"否"只拒绝这一次，下次开机标记还在、弹窗再来；
2. 软件包注册成"驱动更新"随 Windows Update 后台**静默安装**，不询问，更新历史里标为"华硕系统驱动"之类。

第三条通道是驱动盘和官网下载页捆绑的安装器，勾选框默认打勾。

## 品牌位置

| 品牌 | BIOS 开关位置 | 备注 |
|---|---|---|
| 华硕 | 工具（Tool）菜单 → Armoury Crate Configuration/Download → 关闭 | 最激进：BIOS 开关 + 驱动盘捆绑 + 官网默认勾选三层 |
| 微星 | Settings → 高级 → MSI Driver Utility Installer → 关闭 | Windows Update 也会推 MSI Center |
| 技嘉 | Settings → IO 端口等处的 APP Center Download → 关闭 | 相对低调但一样弹 |
| 华擎 | 无此功能 | 四大主板厂唯一不搞这套的 |

## 安全风险

2022~2023 年间 Armoury Crate 被安全研究人员公开多个有 CVE 编号的漏洞（不少是本地提权）。这类软件因要控制风扇、灯效、键盘灯控制器而权限极高，一旦被攻破后果远比普通应用严重。

## 建议与替代方案

- 日常办公家用：直接关（Windows 自带驱动足够覆盖日常）；
- 笔记本用户：键盘灯效、性能模式、电池充电阈值可能依赖官方软件——先关自动安装开关，再手动去官网下载需要的模块，不点一键装全家桶；
- 替代：风扇调速用开源免费的 Fan Control；RGB 灯效用 OpenRGB / Signal RGB；性能模式 BIOS 里原生就有。

## 常见坑清单

1. 点"否"≠ 关闭——开关在 BIOS 里；
2. Windows"可选更新"里也会推送，需一并拒绝；
3. 卸载要用官方卸载工具（华硕有专门的 Armoury Crate Uninstall Tool），控制面板直接卸载会残留服务/注册表、可能被重新激活；
4. 官网下载驱动时捆绑勾选框默认打勾，多看一眼；
5. 关闭此开关与硬件保修无关，放心关；
6. 戴尔/惠普/联想等品牌整机的推送走 OEM 自己的机制，不在主板 BIOS 里解决。
