# DDR5 内存训练与 MCR/PD

> **分类**：BIOS 与固件 · 内存选项
>
> **一句话**：DDR5 平台开机黑屏 30~60 秒是内存训练（Memory Training）在干活；正确绑定 MCR（内存上下文恢复）与 PD（断电模式）可把开机缩到几秒，**绑反了（MCR 开 + PD 关）会蓝屏**。

## 为什么 DDR5 开机慢

JEDEC DDR5 起步 4800MT/s，认证档普遍 6000~6400MT/s 以上：频率越高、信号衰减反射越严重，参数对温度电压极敏感，冷启动与热启动物理状态不同——所以每次都要重新训练四项核心指标：

1. 眼图裕量（信号清晰度）；
2. 时序偏斜（skew，读写时间差）；
3. 端接电阻（抵消反射）；
4. 读写均衡。

训练耗时 30~60 秒，表现为开机黑屏、主板 DRAM 黄灯常亮。DDR4 频率低、训练毫秒级完成无感，故无此选项。

## MCR 与 PD 的定义

| 选项 | 作用 |
|---|---|
| MCR（Memory Context Restore，内存上下文恢复） | 把上一次成功的训练结果（信号校准、时序、电压参考值）打包存储，下次冷启动检测到参数有效直接复用，省掉训练 |
| PD（Power Down，断电模式） | 控制内存空闲/复位时的供电策略：开启时 PHY 层不被彻底断电 |

### 绑定逻辑（核心）

| 组合 | 结果 |
|---|---|
| MCR 开 + PD 开 | ✅ 唯一正确的快速开机方案：快且稳 |
| MCR 关 + PD 开/关 | 开机慢（每次完整训练）但绝对稳定，即出厂默认 |
| MCR 开 + PD 关 | ⚠️ 最危险：PHY 被彻底断电后训练参数失效，复用错误数据就蓝屏崩溃——"拿旧钥匙开新车门" |

### 推荐流程

1. 进 BIOS 把 MCR、PD 都关掉，保存重启；
2. 让系统做一次完整训练（黑屏 30~60 秒属正常，别强行断电）；
3. 进系统用内存测试工具跑一轮稳定性测试；
4. 确认无错后再回 BIOS 把 MCR 和 PD **一起打开**——以后不改频率时序就永远秒开（开机从 30~60 秒缩到约 3 秒）。

## 特殊情况

- **刷 BIOS 或清 CMOS 会清掉训练数据**，第一次开机会重做完整训练，属正常；
- 偶尔冷启动仍慢：电压/环境温度漂移导致旧参数暂时失效，主板自动回退完整训练；
- **冷启动指彻底断电后**（拔电源静置），Windows 内的重启不算、本来就快；
- Intel 平台内存训练策略不同，多数没有这两个选项；
- 调试超频阶段先关 MCR——否则可能拿 4800 的旧参数跑 6000 的频率；极限跑分前也可临时关 MCR 换取即时训练的精准参数。

## 品牌路径参考
