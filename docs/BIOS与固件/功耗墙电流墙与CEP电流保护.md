# 功耗墙、电流墙与 CEP 电流保护

> **分类**：BIOS 与固件 · CPU 电源选项
>
> **风险等级**：🔴 高（改墙前必须理解连锁后果）。本文整理视频内容供理解原理。
>
> **一句话**：频率掉下来很多时候不是温度不够，而是功耗墙先到——拆解 Intel 平台 PL1/PL2/Tau/IccMax 四大参数；降压后跑分反跌则是触发了 CEP 时钟延展保护，表现为"频率数字没变，有效频率被拉长"。

## Intel 四大参数（以 i9-14900K 为例）

| 参数 | 含义 | 官方值示例 |
|---|---|---|
| PL2 | 短时功耗上限 | 253W |
| Tau | 维持 PL2 的时长 | 约 56 秒（随型号差异） |
| PL1 | 长时稳定功耗 | 125W |
| IccMax | 最大核心电流 | 307A（可放宽到约 400A，待核） |

抽水机比喻：PL2 是短时大开度的阀门，Tau 是计时器，PL1 是回落的稳定流量，IccMax 是水管口径。**Cinebench 开局分数高、十几秒后掉分就是 Tau 到期 PL2→PL1，不是电脑坏了。**

三层温度防线：温控降频（插空闲周期）→ 同时降频降压 → **PROCHOT** 强制最低频率。注意主板 VRM 供电过热也会触发 PROCHOT——中低端主板带高端 CPU 性能上不去的常见原因。

## MCE（多核增强）与改墙流程

- MCE 解除全核频率限制并把 PL 拉到参数上限（4095W），实际功耗由散热供电决定——13900K 级什么都不动跑分功耗就能冲 300W+。
- **想自己设 PL 必须先关 MCE，否则数值全被主板覆盖。**
- 三张决策卡：①解锁跑分/渲染——至少 360 水冷 + 高端 Z790 才建议 PL1=PL2=253W、Tau 拉长；②降功耗静音——PL 压到约 125~180W（待核），ITX/静音用户最佳；③排查蓝屏——Tau 到期电压频率跳水也会引发不稳，把 PL1=PL2 设同值让频率曲线更平滑（被忽视的排查手段）。
- 游戏用户 CPU 功耗远低于 PL1，不用动。

**判断撞墙类型**：HWiNFO 跑 Cinebench，封装功耗卡在设定 PL 且频率没掉=撞功耗墙（可拉）；PL 没到频率就掉=撞温度墙（改善散热）；只看频率不看功耗去调墙是盲人摸象。

## 13/14 代背景与寿命

Intel 默认设置保守，是因为高电压高温运行显著增加性能衰减（缩缸/电子迁移）风险——高温+大电流像洪水把导线里的铜原子一点点撞飞，久了导线变细甚至断线。**安全电压不是固定数字，是温度与电压的动态平衡**：散热撑不住天天 95 度，给 1.2V 也在加速损伤。

## CEP：降压跑分反跌的真凶

### 症状

照教程降压 0.05V，跑分反跌；电压加回去分数也不回来。判定标准：**有效频率（Effective Clock）低于核心频率的 90%** 即 CEP（Clock Stretching Protection，时钟延展保护）触发——HWiNFO 里核心频率显示 5500MHz、有效频率 4400MHz，CPU 在"假装高频运行"：每个时钟周期被拉长，实际每秒有效节拍少约 20%。

### 机制

降压后实际电压降了、但 CPU 请求的 VID 没变 → CPU 判定电压不足以维持目标频率 → 触发时钟拉伸补偿 → 表面频率不掉、跑分暴跌。降压后如果出现**视频解码卡顿**，大概率是核显部分（GT CEP）触发。

### 处理

1. 不做降压的用户：保持默认；
2. 做降压的用户：主板有 CEP 开关（IA CEP/GT CEP，华硕在 Advanced → CPU 配置；中高端 B760 最新 BIOS 也开放）的直接**禁用**最彻底；
3. 没有 CEP 开关：用 XTU 小幅电压偏移，-0.05V 起步；
4. 更新最新 BIOS（新微码放宽了 CEP 触发阈值）。

**红线**：关 CEP 后必须用 CoreCycler 重新验证稳定（关之前 CPU"看起来稳"是靠时钟拉伸续命）；不要降压的同时拉频率偏移（必触发 CEP）；0.1V 以内风险不大，别追求极限降压。
