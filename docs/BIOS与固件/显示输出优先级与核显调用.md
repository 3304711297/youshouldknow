# 显示输出优先级与核显调用

> **分类**：BIOS 与固件 · 性能优化项
>
> **一句话**：显示输出优先级（Primary Display）只管开机第一时间点亮哪块显卡输出自检画面；进系统后核显与独显能否同时干活由 iGPU Multi-Monitor（核显多显示器）管——两个选项常在不同子菜单，要分开设置。

## 最常见的"独显睡觉"与黑屏

- 显示器线插在**主板视频口** = 核显输出，游戏全是核显在算，独显躺着睡大觉——不管你插的是多贵的卡。先无脑解法：把视频线挪到**独显金属挡板**的 HDMI/DP 口。
- 反过来的坑：独显插好了、BIOS 默认策略检测到独显后把核显自动屏蔽（断电），此时显示器线插主板口 → **开机黑屏无信号**——这就是"插上独显就黑屏"的唯一原因。
- F 后缀 CPU（如 13400F/KF）没有核显，接主板口怎么折腾都黑屏；Intel 看后缀，AMD 台式只有带 G 的 APU 有核显（锐龙 7000 系全系例外，标配核显）。

## BIOS 里的两个选项

| 选项 | 作用 | 典型位置 |
|---|---|---|
| Primary Display / Initial Display | 开机自检画面从哪输出：Auto（有独显用独显）/ IGFX（强制核显）/ PEG（独显） | 华硕：Advanced → System Agent(SA) 配置；技嘉：Integrated Graphics Configuration；微星：Settings → 高级 → 集成图形配置 |
| iGPU Multi-Monitor（核显多显示器） | 进系统后核显是否与独显同时工作；不开则检测到独显时核显被自动禁用 | 同区域附近，与 Primary Display 分开 |

技嘉 AMD 平台另有"首选显卡/手选显卡"，**一定选独显**——选核显会开机黑屏（开机盲区里画面走主板口）。

## 核显显存（共享内存）

核显被唤醒后要从系统内存划一块当显存：别抠搜留 32MB，设 **128~256MB** 足够点亮和编解码；内存 64GB 以上也别手欠设 2GB——核显只做编解码和页面输出，划太多纯浪费主内存。

## 按场景选

| 场景 | 设置 |
|---|---|
| 纯游戏 | PEG + 关核显多显示器（输出延迟最低、省电） |
| 直播/剪辑 | PEG + 开核显多显示器（独显渲染，核显 QuickSync/VCN 编码推流，各司其职） |
| 双屏办公 | 开核显多显示器，核显带副屏 |
| 纯核显/HTPC | IGFX |
| 服务器/无头机 | Auto 即可 |

> 笔记本是独显直连/混合输出硬件开关控制（配合控制中心），别套用台式机 BIOS 逻辑。

## 验证

- 进桌面后任务管理器"性能"页出现两块显卡（核显 + 独显）；
- 推流/剪辑软件的编码器列表出现 QuickSync（Intel）或 AMF（AMD）即核显编码器就位——编码器不可用多半是核显多显示器没开、或只装了通用驱动（要装完整版核显驱动）；
- 开核显后系统可用内存少 1~2GB 属 DVMT 共享显存，正常现象。
