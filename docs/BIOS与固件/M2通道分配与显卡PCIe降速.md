# M.2 通道分配与显卡 PCIe 降速

> **分类**：BIOS 与固件 · 性能优化项
>
> **一句话**：显卡从 x16 掉到 x8、插上 M.2 后某个 SATA 口突然消失——都不是硬件坏了，是 PCIe 通道被重新分配/物理复用，是设计而非故障。

## 通道从哪来

- 插槽标 x16 不等于跑 x16：槽长是"上限"，实际跑几条（lane）看主板分配。
- 处理器直连通道数量有限（Intel 消费级约 20 条：16 给显卡槽、4 给直连 M.2 等；AMD AM5 约 24 条：16 显卡 + 4 M.2 + 4 芯片组），主板改不了总数，只能决定分给谁。
- **两条路**：① 处理器直连（延迟最低、带宽独立）——显卡槽和第一条 M.2 吃这个；② 芯片组通道（M.2 2/3、多数 SATA 口、USB、网卡等）——共享一条上行链路（等效 x4，部分高端板 x8），大流量并发可能"堵车"。
- HEDT 平台通道多，几乎不共享。

## 三种共享模式

1. 显卡槽与某条 M.2 共享处理器直连通道——插上那条 M.2，显卡 x16 → x8；
2. M.2 复用一组物理收发器——插上 M.2，对应 SATA 口直接失效（硬件层关掉）；
3. 少数 ITX 板双 M.2 都与显卡共享。

## 降 x8 影响多大

- PCIe 4.0 x8 ≈ 3.0 x16 ≈ 16 GB/s；5.0 x8 ≈ 4.0 x16；
- 中端卡多数在误差范围内无感；旗舰卡（4090/5090 级）在 1080P/1440P 高刷下可能掉几个点，4K 基本无感（显卡自己算不过来了）；
- 结论：绝大多数游戏 x8 不是瓶颈，只有吃满带宽的旗舰卡 + 高刷场景才值得为此重新插盘。

## 怎么验证

- **GPU-Z**：看"总线接口"一栏，格式为"当前 x8（最大 x16）"——最大值才是插槽上限，当前值是被借走后的真宽度；
- **待机别下结论**：桌面空闲时链路省电，速度会降到 1.1——跑渲染测试或游戏压满负载再看；
- BIOS 系统信息里也能看扩展槽 Link Width；
- 插 M.2 后 SATA 口消失：进 BIOS 看端口列表哪个灰掉，对照说明书换口。

## BIOS 手动分配

多数主板提供"扩展槽带宽分配/显卡链路速度/M.2 带宽"选项（华硕在扩展槽子系统相关项、微星另有分配项、技嘉在 PCIe 槽配置、华擎在 AMD 底层设置/高级）。可以主动把显卡槽让给 M.2 组阵列或万兆卡——这是有意为之的功能，不是故障。清 CMOS 后手动分配会回默认，但**物理复用关系不受清 CMOS 影响**。

> 警告：别盲目在 BIOS 强制显卡 x16——可能把 M.2 挤到 x2 甚至直接失效。取舍看用途，不是数字越大越好。

## 实操建议

1. **装机前翻说明书"通道分配图"**：看显卡槽是否直连、哪条 M.2 与显卡共享、哪些 SATA 口会被禁用，照图插一步到位；
2. 系统盘插第一条（直连）M.2；加盘选明确走芯片组的 M.2；
3. 显卡永远优先第一根（直连）槽；第二根长槽常见只 x4；
4. 想保满速 SATA 口：别插被复用的口，或把盘换到不被共享的口。

## 误区澄清

- "主板缩水"——是分配设计，不是缩水；
- "显卡坏了"——只是降速，x8 几乎无感；
- "SATA 盘坏了"——大概率被 M.2 复用顶掉了；
- 任何调整前数据先备份；重排插法无破坏性。
