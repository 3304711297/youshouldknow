# PBO 基础与性能释放总闸门

> **分类**：BIOS 与固件 · CPU 自动优化
>
> **风险等级**：🟡 中（设置风险低、稳定性风险中等）。开 PBO 门槛低且可随时回滚 Auto，但高温、WHEA 报错及主板供电压力是真实物理约束。
>
> **一句话**：CPB 是 AMD CPU 自动加速的总开关（关了即失去正常睿频），PBO 则是性能释放的「天花板调节器」（只放宽功耗/电流/温度三面墙，让高频驻留更久）；它属于自动超频而非锁频锁压的传统手动超频，真实上限永远取决于散热。

---

## 适用范围与前置认知

- **支持平台**：AMD 桌面平台，涵盖 **AM4** 与 **AM5**（从锐龙 3000 系列起确立现行 PBO 体系；更早的锐龙 1000/2000 系列调频机制不同）。
- **设备类型**：以 DIY 组装机与品牌台式机主板为准。笔记本移动端（如锐龙 HS/HX 系列）受整机功耗封装、OEM 固件调校与模具散热约束，策略因厂商而异，不直接套用桌面端选项逻辑。
- **BIOS 菜单常见路径**：
  - 路径一（AMD 官方标准入口）：`Advanced`（高级模式）→ `AMD Overclocking`（AMD 超频）→ `Precision Boost Overdrive`；
  - 路径二（底层平台菜单）：`Advanced` → `AMD CBS` → `NBIO Common Options` → `SMU Common Options`；
  - 路径三（主板厂商快捷入口）：华硕 `Ai Tweaker` / `Extreme Tweaker`、微星 `OC` 菜单、技嘉 `Tweaker`、华擎 `OC Tweaker` 等顶级超频页面。
- **前置必备操作**：动手前务必确认自己掌握进出 BIOS 保存设置，以及清空 CMOS 恢复出厂设置的方法（详见 [BIOS 入门：进入、退出与模式切换](./BIOS入门进入退出与模式切换.md) 与 [BIOS 恢复默认设置的三种方法](./BIOS恢复默认设置的三种方法.md)）。

## 核心概念解耦：CPB vs PBO

在进入 AMD 超频菜单时，绝大多数用户最容易混淆的两个基础开关是 **CPB** 与 **PBO**。一个管「有没有自动加速」，另一个管「自动加速的天花板有多高」。

```text
┌───────────────────────────────────────────────────────────────┐
│              Core Performance Boost (CPB)                     │
│                 【CPU 自动加速总闸门】                          │
│                                                               │
│   关闭 (Disabled)：剥离动态加速，频率跌回基频附近                │
│   开启 (Auto / Enabled)：允许根据负载与余量动态冲高频           │
└───────────────────────────────┬───────────────────────────────┘
                                │ 开启状态下
┌───────────────────────────────▼───────────────────────────────┐
│            Precision Boost Overdrive (PBO)                    │
│                 【功耗与电流天花板调节器】                      │
│                                                               │
│   Auto：出厂官方功耗/电流墙限制，撞墙即回退                      │
│   Enabled / Motherboard：外推三面墙天花板，高频驻留更久          │
└───────────────────────────────────────────────────────────────┘
```

### 1. Core Performance Boost（CPB，核心性能加速）

- **功能定位**：AMD 处理器动态睿频加速的**总闸门**。
- **默认取值**：通常为 `Auto` 或 `Enabled`（不同主板厂商字符标识略有差异）。
- **工作机制**：开启后，CPU 内部微控制器会实时监控运行负载、芯片温度与供电电流余量，只要环境允许，便会自动将核心频率推升至标称加速频率。
- **误关后果**：若在 BIOS 中手滑将 CPB 改为 `Disabled`，CPU 将彻底失去动态加速能力，单核与多核满载时频率大幅回落，跑分直接腰斩。很多玩家误以为是 CPU 损坏或主板缩水，根因往往只是误碰了 CPB。
- **基频澄清**：关闭 CPB 后，CPU 并不一定会严格死锁在官方标称的基准频率（Base Clock）上。例如锐龙 5 5600 标称基频为 3.5 GHz，实际关闭 CPB 后的驻留频率会受到不同主板供电调配与微码版本的影响，切勿将其视作绝对固定值。
- **处置原则**：**日常使用严禁关闭**。仅在排查早期主板内存兼容性、做整机基准功耗对照测试或定位硬件死机故障时，作为经典排错手段临时关闭。

### 2. Precision Boost Overdrive（PBO，精准频率提升超频）

- **功能定位**：突破 AMD 官方出厂保守限制的**性能释放总闸门**。
- **超频定性**：PBO 属于**自动超频（Auto Overclocking）**，但**不是**固定倍频、固定电压的传统手动超频（Manual Overclocking）：
  - 传统手动超频：将所有核心全核锁死在固定倍频（如 5.0 GHz），电压也钉死在固定值，不随负载动态起伏；
  - PBO 自动超频：完全不碰死锁频率与电压，而是把限制核心自动冲频的功耗、电流与温度「三面墙」向外推宽。
- **性能收益原理**：锐龙核心的睿频逻辑是**见缝插针式加速**。在默认限制下，只要多核重载一开，功耗或电流迅速触顶，高频瞬间即逝；当 PBO 把三面墙放宽后，核心在重载下撞墙大幅延缓，能在高频区间驻留更长时间。
- **收益不对称性**：多核长时间持续高负载（如 Cinebench 渲染、视频压制、复杂编译）收益最明显；而在日常轻载单核场景以及大部分游戏中，CPU 本身并未触及功耗墙上限，提升往往极小甚至在误差范围内。

## 三面墙与温度上限

PBO 放宽的「天花板」，在硬件底层由三组核心限制参数构成，俗称「三面墙」：

| 限制项 | 全称与中文 | 物理意义 | 典型影响场景 |
| :--- | :--- | :--- | :--- |
| **PPT** | Package Power Tracking<br>全封装功耗墙 | 规定整个 CPU 封装允许摄取的最大电功率（瓦特，W） | 全核满载功耗上限，约标称 TDP 的 1.35 倍（如 65W TDP 默认 PPT 约 88W） |
| **TDC** | Thermal Design Current<br>持续电流墙 / 热设计电流 | 约束主板 VRM 供电在长期持续重载下的耐受电流（安培，A） | 长期高温重载（如连续渲染压测），限制供电模块长期发热 |
| **EDC** | Electrical Design Current<br>瞬间电流墙 / 电气设计电流 | 约束短时间内（瞬态突发峰值）VRM 供电所能供给的峰值电流（安培，A） | 瞬态高负载爆发力，直接影响日常操作与程序启动的瞬态响应体感 |

### 概念勘误

1. **TDC 不是温度墙**：虽然英文叫 *Thermal* Design Current，但其中的「Thermal」指供电硬件的热工程设计规范，数值单位是安培（A），绝非核心摄氏度温度。
2. **温度上限不是第四面墙**：主板中的 Platform Thermal Throttle Limit（如 95℃ / 89℃ / 85℃）是 CPU 内部的安全底线保护机制。一旦核心温度达到设定上限，不论三面墙推得多么宽松，CPU 都会触发热节流自保，立即强制降频降压。

## 四种模式横向评测与选择

在 BIOS 的 PBO 菜单中，常见以下四种工作模式：

| 模式 | 运行机制 | 适用人群与硬件要求 | 稳定性评级 |
| :--- | :--- | :--- | :--- |
| **Auto** | 严格遵循 AMD 出厂规范限制，功耗与温度可控 | 适合追求长期稳定、原装散热或中低端主板用户 | ★★★★★ |
| **Enabled** | 启用 AMD 官方预设的一组放宽值，无需手动输数值 | 想小幅释放性能的进阶用户，起步推荐 | ★★★★☆ |
| **Motherboard** | 完全听从主板厂商定义的激进供电预设（放宽至主板 VRM 上限） | 中高端主板（如良好供电的 B650/X670/X870）且配备强力水冷/双塔风冷 | ★★★☆☆ |
| **Advanced** | 彻底开放自定义：手动调节 PPT/TDC/EDC、标量 Scalar、频率偏移等 | 极限玩家、追求精细化能效比或分核调校（第二季后续展开） | 自定义 |

### 核心调优原则

1. **循序渐进**：日常释放建议从 **Enabled** 起步，测试温度与稳定性均表现良好后，若主板供电与散热具备充足余量，再尝试开启 **Motherboard**。
2. **能否突破标称最高加速频率**：开启 PBO 基础模式仅代表放宽功耗/电流墙，使加速撞墙变慢；能否突破出厂最高单核加速频率（如标称 5.0 GHz 冲到 5.2 GHz），取决于具体 CPU 型号、主板 BIOS 微码策略以及是否在 Advanced 模式下配置了 **Boost Clock Override（加速频率偏移）**。不能脱离平台一概而论。
3. **真实上限是散热**：PBO 选项只是纸面配额，真实约束是机箱风道与散热器能力。如果散热性能不足，开启 Motherboard 模式后瞬间撞上 95℃ 温度上限，频率反而会剧烈上下跳动，造成帧率抖动与性能倒退。

## 厂商一键预设与周边选项辨析

### 1. 厂商一键马甲模式

许多主板厂商在 BIOS 显眼位置提供了自家命名的「一键性能增强」开关（如微星 Performance Switch / Enhanced Mode、华硕 PBO Enhancement、技嘉 Performance Boost 等）。

**技术真相**：厂商一键预设往往不是单纯的 PBO 切换，而是将多项底层设置打包绑定的复合配置。

**六项对照核查法**（开启一键预设前，建议手机拍照记录以下 6 项默认值）：
1. **PBO 基础状态**：是否从 `Auto` 变更为 `Enabled` 或 `Advanced`；
2. **三面墙数值**：PPT、TDC、EDC 是否被板厂直接拉满或赋予高额数值；
3. **温度上限（Thermal Limit）**：是否被锁在 85℃ / 75℃ 或放宽到 95℃；
4. **加速频率偏移（Boost Clock Override）**：是否被暗中增加了 +100 MHz 或 +200 MHz；
5. **曲线优化器（Curve Optimizer）**：是否偷偷内嵌了全局降压负偏移（如全核负 10 或负 20）；
6. **电压与内存设置**：CPU SoC 电压、VDDCR 电压或防掉压等级（LLC）是否被改动。

微星在部分锐龙 9000 平台提供的增强模式官方文档明确说明其联动调整了温度点与功耗限制，这属于特定平台与特定 BIOS 的特化方案，切勿将其宣传的提升百分比直接套用到所有主板上。

### 2. PBO 与 EXPO 的独立性

- **PBO**：负责 CPU 核心加速行为、功耗与电流释放边界；
- **EXPO**：负责 DDR5 内存一键加载认证超频档（时序、频率、内存电压）；
- 两者在主板上属于相互独立的两个总线控制域，可同时开启。若开启后出现系统蓝屏或游戏闪退，必须使用排除法定位，切勿盲目把内存超频不稳归咎于 PBO。

## X3D 处理器边界重大更新

对于锐龙 3D V-Cache 系列处理器用户，必须注意新老世代的规则变革，严禁以偏概全：

| 世代典型代表 | 核心架构与 3D 堆叠设计 | 超频与调节能力 | 调校主攻方向 |
| :--- | :--- | :--- | :--- |
| **早期型号**<br>（如 5800X3D / 7800X3D） | 缓存芯片堆叠在计算核心（CCD）上方，热阻较大且缓存对高电压极其敏感 | 传统倍频与正向加速频率偏移严格受限 | **PBO + Curve Optimizer 负压降温**：通过降低运行电压压制发热，让核心能在官方加速上限内跑得更满更久 |
| **新世代型号**<br>（如 9800X3D） | 3D V-Cache 结构下移至 CCD 核心下方，计算芯片直触均热盖，导热效率彻底解放 | 官方规格页明确标注**「已解锁以进行超频」（Unlocked for Overclocking）**，官方定性首款完全解锁超频的 X3D 处理器（基准 4.7 GHz，加速 5.2 GHz） | 传统手动倍频调节、全套 PBO、正向频率偏移与高级曲线优化均全面可用 |

**操作法则**：必须以自己手中具体的 CPU 型号及主板官网最新 BIOS 说明为准，绝不能把 7800X3D 的设置禁忌盲目套用到 9800X3D 上。对于多 CCD 的 X3D 型号（如 7950X3D / 9950X3D），由于涉及缓存 CCD 与高频 CCD 的异构调度，调校策略更为复杂（后续专篇展开）。

## 稳定性验证「四件套」与翻车回滚

### 1. 验证四件套

调完 PBO 进系统后，严禁仅凭「能进桌面」或「跑了一遍鲁大师」就宣称稳定，必须跑满以下四件套：

1. **HWiNFO64 观察「有效频率」（Effective Clock）**：
   - 重点看持续重载下的有效频率均值，不要被单核心在毫秒级瞬时跳出的「表面最高频率」所蒙蔽；
2. **基准性能前后对比**：
   - 使用 Cinebench R23 / 2024 等工具在开启前后各跑一轮。单轮跑分只能看性能趋势，不能证明系统绝对稳定；
3. **关键物理指标三联记录**：
   - 将核心温度（Tctl/Tdie）、全封装功耗（CPU Package Power）与风扇转速同步记录对比。只看跑分涨幅而不看温度和功耗激增的做法缺乏工程意义；
4. **排查 Windows 系统日志与 WHEA 硬件报错**：
   - 打开 Windows 事件查看器，在「系统」日志中筛选 `WHEA-Logger` 事件（如事件 ID 18、19）。在轻载待机、鼠标轻微晃动或退出游戏切回桌面瞬间若产生 WHEA 警告，说明供电边缘失稳。

### 2. 翻车症状与回滚 SOP

- **翻车现象 A：开启 Motherboard 后性能反而下降、帧率剧烈掉帧**：
  - **根因**：瞬间撞上温度上限触发热保护降频；
  - **处置**：退回 `Enabled` 模式，或更换散热器、重涂硅脂、优化机箱风道。
- **翻车现象 B：蓝屏崩溃、频繁自动重启**：
  - **处置第 1 步**：重启按 Del 键进入 BIOS，将 PBO 模式直接切回 `Auto`，90% 的启动与稳定性问题可立即解除；
  - **处置第 2 步**：若依然无法正常进系统，直接选择 `Load Optimized Defaults`（加载最优默认值），按 F10 保存重启。

## 核心三句速记

1. **CPB 是自动加速总闸门**：日常坚决保持开启，非故障排查绝不手滑关闭。
2. **PBO 是性能释放天花板**：它属于自动超频，不锁固定倍频与电压；放宽功耗与电流墙，真实上限由散热决定。
3. **Auto 最稳、Enabled 起步**：普通用户选 Auto，想释放性能从 Enabled 试起，散热强悍再上 Motherboard。
