# BIOS 信息查看与安全小项：密码、SPD、ME/PSP 与 Easy Mode

> **分类**：BIOS 与固件 · 选项科普
>
> 本文整理自重制版第 21 集（第一季收官），覆盖四个"看与防"性质的小项：BIOS 密码、SPD 内存信息、ME/PSP 固件版本、Easy Mode 界面切换。**这四个选项不涉及性能调校**，收益是"看得懂"和"回得来"。

## 一句话结论

| 选项 | 编号 | 风险 | 核心价值 |
|---|---|---|---|
| BIOS 密码 | BIOS-10 | **中**（不伤硬件，代价在忘记） | 防他人改设置，但防不住拆机 |
| SPD 信息 | BIOS-11 | 零（只读） | **验货**：确认内存支持 XMP 还是 EXPO |
| ME / PSP 版本 | BIOS-12 | 查看零风险；**若去改则高危** | 排查"开机恰好 30 分钟关机" |
| Easy Mode | BIOS-15 | 零（纯界面切换） | 别被满屏英文劝退 |

> 编号说明：`BIOS-10 / 11 / 12 / 15` 是本系列的**选项 ID**，不是"第 10~15 期"。全集编号不连续（本期只涉及这四个）。

## 一、BIOS 密码（BIOS-10）

### 两级密码的区别

| 类型 | 作用 | 何时被要求输入 |
|---|---|---|
| `Administrator Password`（管理员密码） | 挡住进入 BIOS 设置界面的权限 | 开机按 `DEL` 进 BIOS 时 |
| `User Password`（用户密码） | 仅控制进入操作系统的引导权限 | 开机引导阶段 |

一句话区分：**进 BIOS 用管理员密码，只进系统用用户密码**。两者都设时，管理员密码用于进设置界面，用户密码用于日常开机引导。

### 密码存在哪：CMOS / RTC 内存

- 主板官方文档的口径：**CMOS 里保存的是实时钟（RTC）内存的内容**——里面装着日期时间、**BIOS 密码**、以及**你的全部设置参数**（启动顺序、XMP/EXPO、风扇曲线等）；
- 因此**清 CMOS = 密码与全部设置一起归零**。这是清密码的唯一途径，也是它的代价。

### 红色警告：三处代价与局限

1. **清 CMOS 是"连坐式"重置**：不只清密码，日期时间、启动顺序、内存认证档（XMP/EXPO）、风扇曲线全部回出厂。清完必须重新配置；
2. **BIOS 密码防不住拆机**：密码在固件层面，硬盘拆下来接到别的机器上照样能读。真要防数据泄露，靠的是**磁盘加密**（如 BitLocker），不是 BIOS 密码；
3. **笔记本/品牌机的密码常与序列号绑定**：这类机器清 CMOS 清不掉密码，只能返厂。本攻略的主战场是**台式 DIY 主板**。

### 修改与撤销

- **改密码**：进密码设置项 → 输旧密码 → 输两次新密码 → 保存；
- **撤销密码**：进入密码设置项 → 输旧密码 → 在 `New Password` 与确认框中**直接留空回车** → 保存退出即清除。

### 忘记密码后的三种清 CMOS 做法

**操作前务必断电（拔掉电源线）**：

| 方法 | 做法 | 适用 |
|---|---|---|
| 按键 | 按主板后置 I/O 挡板上的 `Clear CMOS` 按钮 5~10 秒 | 有该按钮的中高端主板 |
| 短接排针 | 用螺丝刀/跳线帽短接 `CLR_CMOS`（华硕为 `CLRTC`）针脚 5~10 秒 | 最通用 |
| 抠电池 | 取下 `CR2032` 纽扣电池，等 5~10 分钟装回 | 无按钮无排针的老主板 |

> 电池反装同样能断电清 CMOS，但正装才是正确装法，别把反装当成常规手段。

**清完的收尾三步**：开机按 `F1` 进 BIOS → 按 `F5` 载入默认设置 → 重设必要项后按 `F10` 保存退出。

## 二、SPD 信息（BIOS-11）

### SPD 是什么

`SPD`（Serial Presence Detect）是**内存条 PCB 上的一颗独立 EEPROM 小芯片**，出厂固化记录了这根内存的：

- 厂商与 `Part Number`（料号）；
- 时序（Timings）、频率、电压；
- 支持的认证档：**Intel XMP** 或 **AMD EXPO**。

**关键认知：SPD 在内存条上，不由 BIOS 生成**。BIOS 只是"读"它，改不了它。

### 最重要的一条：SPD 页是只读的

- BIOS 里的 SPD 页面**只读**（华硕菜单里直写 `Read only`），在此页面**无法开启 XMP/EXPO、无法改任何参数**；
- 要开内存认证档，去 **超频菜单**（华硕在 `Ai Tweaker`，微星在 `OC`）；
- SPD 告诉你的是内存**"能跑多少"**，**不等于"现在跑多少"**。

### 菜单路径（华硕 / 微星）

| 厂商 | 路径 |
|---|---|
| 华硕 | `Tool` → `ASUS SPD Information` |
| 微星 | `OC` → `Memory-Z` → `DIMM Memory SPD` |

### 二手验货用法

这是 SPD 最实用的场景：进 SPD 页面读 `Part Number`，与内存条外壳贴纸核对是否一致，可识别贴牌/换标条；同时确认它支持的是 XMP 还是 EXPO——买错平台认证档的条子，开不了认证档。

## 三、ME / PSP 版本（BIOS-12）

### 是什么

| 平台 | 名称 | 全称 |
|---|---|---|
| Intel | **ME** | Management Engine（管理引擎） |
| AMD | **PSP** | Platform Security Processor（平台安全处理器） |

共同点：**独立于主 CPU 和操作系统的子系统，有自己的固件，比操作系统启动得更早**。

### 为什么"不能乱动"：30 分钟看门狗

- ME 固件（v6.0 及以上）带**硬件级签名校验**。引导 ROM 找不到带有效签名的 ME 固件时，主板看门狗（Watchdog Timer）会兜底：**整机开机后恰好 30 分钟强制关机**；
- 这个"精准 30 分钟"是识别 ME 固件异常的典型特征——不是散热问题，也不是电源问题；
- 消费级平台**无法彻底关停 ME**。处置原则只有一条：**只看不改**，绝不擦除、不解包修改。真出故障，走"刷回完整官方 BIOS"恢复。

### 查看位置与判读

| 平台 | 路径 | 字段 |
|---|---|---|
| Intel（华硕） | `Main` 页（EZ Mode 概览即可见） | `ME FW Version` |
| Intel（微星） | `Advanced` → `PCH-FW Firmware Versions` | 固件版本列表（只读） |
| AMD（技嘉） | `Advanced` → `PSP Firmware Versions` | `PSP Firmware Version`（只读） |

**判读判据**：版本号正常显示即健康；若显示 `0.0.0.0` 或**直接空白**，说明 ME 固件已损坏或未成功加载，**必定触发看门狗关机**，需立即重刷带完整 ME 模块的官方 BIOS。

> 看门狗 30 分钟关机是"兜底"，不是"惩罚"：它保证机器还能进系统做抢救。所以遇到 30 分钟关机先查 ME 固件，别急着换电源。

## 四、Easy Mode 界面切换（BIOS-15）

- **作用范围仅限界面**：Easy Mode 与 Advanced Mode 决定你进 BIOS 第一眼看到哪个画面，**不改动任何硬件功能与参数**；
- **切换键**：华硕按 `F7` 在两模式间切换；
- **默认值各板不同**：出厂默认进哪个模式由主板厂商决定，以实机为准；
- 华硕的路径在 `Boot` → `Setup Mode`（决定默认进哪个模式）。

对于"一进 BIOS 满屏英文不敢动"的情况，切 Easy Mode 是零风险的第一步——它只换界面，不动设置。

## 五、二手交易验货检查清单

进 BIOS 五分钟即可完成的两项验货：

1. **验内存**（防贴牌/假条）：`SPD Information` 页读 `Part Number` 与条身贴纸比对；确认 XMP 还是 EXPO；
2. **验主板**（排查 30 分钟关机隐患）：`Main` 页看 `ME FW Version`，确认非 `0.0.0.0` 且非空白；异常说明主板的 ME 固件有问题，需重刷官方 BIOS 才能恢复正常使用。

---

## 六、验证方式：怎么算做对了

- **密码**：设定后重启，密码状态由 `Not Installed` 变为 `Installed`，且开机时确实要求输入——说明生效；
- **SPD 页面**：能读到 `Part Number` 与认证档类型即为正常（该页只读，不存在"改错"）；
- **ME / PSP**：能看到版本号（非 `0.0.0.0`、非空白）即为正常；
- **Easy Mode**：`F7` 能在两模式间来回切换即为正常。
