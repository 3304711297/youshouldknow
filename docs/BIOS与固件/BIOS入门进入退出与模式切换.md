# BIOS 入门：进入、退出与模式切换

> **分类**：BIOS 与固件 · 入门必读
>
> **目标**：能稳定进入 BIOS、能在简易/高级两种模式间切换、能不保存误改并安全回到系统。本期只看不乱点，超频、启动等具体选项留待后续文章逐项拆解。

## 怎么进 BIOS

- 台式机最常见按 **Del**；部分主板和笔记本常用 **F2**；笔记本按键由整机厂决定，部分需要配合 Fn 键，请查整机说明书。
- **时机是关键**：按下电源键后立刻开始点按，每秒 2~3 次，抢在 Windows 启动前；不要长按、也不要乱拍一排按键。
- 重启时同样可以操作：等屏幕显示重启、重新开始自检时，再点按 Del 或对应按键。
- 看到 Windows 转圈，说明这次已经错过了——等正常重启后再来一次。

### 进不去的三个常见原因

1. **键盘没就绪**：无线接收器、扩展坞、机箱前置 USB 口在开机自检阶段可能尚未初始化——换成有线键盘，接主板后置 USB 2.0 口（通常为黑色）。
2. **Fast Boot 缩短了窗口**：BIOS Fast Boot 会缩短按键窗口。注意 **BIOS Fast Boot 与 Windows 快速启动是两套机制**，详见[快速启动 Fast Boot](./FastBoot快速启动.md)。
3. **一直黑屏**：那可能根本没完成 POST，不是按键问题——去看主板诊断灯（DEBUG 灯）、数码管代码或蜂鸣器报警组合，这些才是第一线索。

### Windows 11 备用入口

设置 → 系统 → 恢复 → 高级启动 → 立即重新启动 → 疑难解答 → 高级选项 → **UEFI 固件设置** → 重启。

> 注意：这条路径不一定必然出现。若没有"UEFI 固件设置"入口，不代表 Windows 坏了，可能设备正在用 Legacy 启动或本身不支持，此时回到开机快捷键方案。

## 两种界面模式

| 模式 | 内容 | 适用 |
|---|---|---|
| EZ Mode（简易模式） | 频率、风扇、内存、存储、启动设备速览 | 快速查询状态 |
| Advanced Mode（高级模式） | 菜单更完整 | 找具体选项、后续系列操作基本都要进高级模式 |

- 切换按键各品牌常见 F7/F2/F6 等，**不是统一标准**，型号与版本都可能不同——以屏幕边缘提示为准；若 F 键被映射为音量/亮度，笔记本可能需同时按 Fn。
- 也可以用鼠标点击界面里的模式切换按钮来回切换。模式切换不会修改任何参数。

## 保存与放弃更改

- 退出时多数主板 **F10** = 保存并退出，具体以屏幕提示为准。
- 按 F10 后别急着确认：先看弹出的**变更摘要**，摘要为空或明确写"没有变化"再继续。
- 出现陌生项目立刻取消，回到退出菜单选 **Discard Changes（放弃更改）**——不保存退出最可靠，不要凭感觉手动改回原始值。

## 验证清单

1. 能稳定进入 BIOS；
2. 能在两种模式间切换；
3. 能放弃误改并回到系统。

之后每篇文章的操作都以这套动作为底座：通电点按 Del/F2 → 模式切换以屏幕提示为准 → 陌生变更一律不保存。
