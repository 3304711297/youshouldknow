# BIOS 恢复默认设置的三种方法

> **分类**：BIOS 与固件 · 入门必读
>
> **风险等级**：🟡 中。三层恢复手段清理范围不同，搞错层级要么白忙活，要么把不该清的（密码、密钥、BitLocker 触发条件）一起清了。

## 适用场景

BIOS 里改乱了、超频翻车点不亮、忘了 BIOS 密码、刷 BIOS 后系统莫名不稳——这时候需要的往往不是继续改，而是把设置恢复回"已知良好"状态。恢复不是一句话，至少有三个层级。

## 第一层：Load Optimized Defaults（恢复厂商推荐）

- 用厂商预置的推荐值覆盖当前设置，**不是把主板清零**。
- 快捷键常见值：华硕多为 F5、微星多为 F6、技嘉新 UEFI 界面多为 F7，部分老主板 F9——一切以屏幕底部提示为准。
- **清理范围**：一般会把手动超频的频率和电压、内存认证档（XMP/EXPO）恢复回默认；**一般不清 BIOS 管理员密码**（密码存放在独立安全区域）。

## 第二层：Load Setup Defaults / Load UEFI Defaults

- 华擎常叫 Load UEFI Setup Defaults，其他品牌叫 Load Setup Defaults。
- 恢复成 UEFI 固件的**出厂默认**，比 Optimized 更纯粹；差别只在厂商预设值上，两者同样**不清 BIOS 密码**。

## 第三层：Clear CMOS（物理清空）

用硬件手段让设置芯片（NVRAM）寄存器断电丢数据，下次开机固件找不到有效配置，自动回到最原始出厂默认。三种物理方式：

1. **跳线**：关机断电，用跳线帽短接 CLRCMOS 两针几秒再移回原位；
2. **按钮**：部分主板 I/O 面板或板载有 Clear CMOS 实体键，断电按住几秒；
3. **拔电池**：关机拔电源，按开机键放余电，取下 CR2032 纽扣电池等几秒装回。

**Clear CMOS 是全清**：超频、启动顺序、时间、Secure Boot、TPM 配置（密钥保留、测量基线重置）全部重置。⚠️ 勘误（2026-09-12 核实）：BIOS 管理员密码多存独立 EEPROM/NVRAM 安全区，Clear CMOS 通常**清不掉**——仅老式主板例外。一句话记忆：**想清密码先查平台年代，现代平台清 CMOS 白忙；只想回厂商推荐用 Load Optimized；Clear CMOS 才是全清。**

## 原理速记

- BIOS 设置存在设置芯片内存（NVRAM，纽扣电池供电）与固件芯片内的设置存储区中；
- Load Defaults 类：用内置预设表覆盖当前值，不碰寄存器全清——所以快、可逆、再改回去就行；
- Clear CMOS：断开供电让内容丢失，设置存储区部分变量可能跟着重置。

## 操作要点与配置文件迁移陷阱

### 1. 配置文件（Profile）的保存与跨版本兼容性
- **保存介质**：现代主板支持将调优参数保存至板载 NVRAM 槽位（Profile Slot 1~8），或导出为外置 U 盘配置文件（如 `.CMOS` / `.DAT` / 文本文件）；
- **跨版本迁移陷阱（严禁盲目导入旧配置）**：更新主板 BIOS 后，底层固件的 NVRAM 变量偏移量（Offset）、寄存器结构与微码定义往往已发生重构。强行将旧版本导出的 Profile 导入新版 BIOS，极易因参数错位引发主板自检卡死（如停在 DRAM/CPU 报错代码）、黑屏甚至无限重启；
- **正确姿势**：BIOS 升级前，**务必使用手机对关键设置页面（风扇曲线、PBO/降压、内存时序、启动项）逐页拍照归档**；刷入新 BIOS 并重新训练通过后，按照片手动重新输入，切勿依赖跨版本一键导入。

### 2. 两个翻车高发红线
1. **大版本 BIOS / AMD 固件更新后，让内存完整重训**：别直接套用旧的高频时序，让主板在默认或基础 XMP 下重新训练稳定后，再逐步拉升参数；
2. **别在 Secure Boot / TPM 开启状态下随手 Clear CMOS**：会重置安全密钥与可信平台模块配置、改动 PCR 测量值，开机触发 **BitLocker 恢复密钥**（48 位）。操作前先在系统里暂停 BitLocker 保护，或提前到微软账户获取恢复密钥。

### 清完后注意

- 首次开机可能提示按 F1 继续（重新设置），AMD 平台可能提示重新训练内存（"内存上下文已变更"类提示），不必恐慌；
- 确认超频消失、内存认证档关闭、启动顺序重置后，按归档记录手动恢复设置。

### 静电与操作细节

- 操作前双手碰一下机箱金属部分释放静电；不拔电源直接短接可能无效；
- 电池装反会接触不良，等够几秒再装回。
