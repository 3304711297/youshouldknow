# AMD PBO 与 Curve Optimizer

> **分类**：BIOS 与固件 · CPU 自动优化
>
> **风险等级**：🔴 高（涉及降压与频率解锁）。本文整理视频内容供理解原理，实际降压幅度必须以自己平台的稳定性测试为准。
>
> **一句话**：PBO 本质不是直接让 CPU 变快，而是把 PPT/TDC/EDC 三堵"限制墙"往外推；Curve Optimizer（CO）负偏移=按 V/F 曲线智能降压，才是 PBO 的真正核心——只调 PBO 开关和频率偏移，效果只发挥了三成。

## 前提与模式

- **芯片组支持**：AM5 的 X670E/X670/B650（及 X870 系）支持，**A620 不支持**；AM4 的 B550/X570 支持，A520/A320 不支持——找不到选项不是翻错地方，是硬件不存在。PBO 属 AMD 官方功能，不算越界超频。
- **五种模式**（保守→激进）：禁用（锁死所有加速机制，**恢复默认请选"自动"而不是"禁用"**）→ 自动（出厂默认）→ 启用（够用）→ 高级模式（手动解锁三堵墙，带默认参数）→ 主板预设。中高端板（X670+）选主板预设，B650 这类入门板选高级模式。

## 三堵墙与频率偏移

| 墙 | 含义 |
|---|---|
| PPT | 全封装功耗目标（W），通常约标称功耗的 1.35 倍 |
| TDC | 持续电流墙（A），管长时间高负载 |
| EDC | 峰值电流墙（A），管瞬间爆发，影响日常响应体感 |

- **频率偏移（Boost Override）**：默认 0，可 +100~200MHz，最终能否跑到看体质和散热。
- **温度目标**：PBO 菜单里的平台温控预设（如 85/75 度）——设了之后 PBO 自动管理三堵墙不超上限；散热压不住时手动设温度墙（如 85 度）比硬扛 95 度更合理。

## Curve Optimizer 深拆

### 原理链

负偏移 → 每个频率点所需电压下降 → 同频功耗发热减少 → PBO 检测到温度余量 → 自动提频一档。CO 比传统固定毫伏降压更智能：它**自适应地把整条 V/F 曲线下移**（每个频率点的电压整体下移 N 个单位，低频给得低、高频给得高），算法仍在工作。

### 三张设置卡

1. 模式：全核统一 / 每核独立 / 方向（负=降压）；
2. 幅度：1~30，**是抽象单位不是毫伏**——同样 -20 在不同 CPU 上的实际降压幅度完全不同，别和别人比数值；
3. 全核 vs 分核：全核上限由最弱那颗核心决定；分核精调可多挤出 50~100MHz，但需要 8~12 小时的单核轮巡测试。

### 起步参数（视频口径）

- Zen3 全核从 -10 起步、Zen4/Zen5 从 -5 起步（待核），每次调 5，稳了再加；
- Zen4/Zen5 普通体质 -20~-25 通常到头，别硬拉 -30；
- **X3D 更保守**（-10 起步，待核）：缓存温度敏感、电压拓扑不同，别照搬普通锐龙的"最佳参数"；
- 分核与直觉相反：频率最高的"黄金核心"出厂曲线已被压过、往往只能扛 -10~-15，普通核心反而能吃 -25~-30；双 CCD 以最弱 CCD 为准、整体比单 CCD 保守 3~5 个单位。

## 稳定性验证（真正的考场）

- **满载烤机不是终点，桌面空载/低负载才是 AMD 降压的坎**：待机时频率几百 MHz、基础电压可能只有 0.8V，负压太狠会把这点电压砍到物理极限以下——挂机时"睡着睡着数据就错了"，鼠标一动瞬间蓝屏。**挂机测试**：开 10 个浏览器标签放一整天，不蓝屏不重启才算稳。
- **单核轮巡**：CO 最易崩溃场景是单核轻载、低电流瞬间频率切换——用 CoreCycler 每核 30~60 分钟轮巡；Prime95 全核通过≠稳。
- **WHEA 判蓝屏归属**：事件查看器里崩溃前有 WHEA 事件（描述提到 CPU/Cache）→ CPU 电压真不够，回调负压；事件 ID 18 看硬件错误、ID 17/19 多是内存或 USB 的锅，别冤枉 CO。
- **时钟拉伸自查**：CO 负压过激会触发有效频率下降（表面 5.5GHz、有效 5.0GHz）——每次改完跑 Cinebench 记录分数，比默认低超 1% 就是负压给大了（CO 是为了同性能更低温，不是降频换低温）。

## 常见误区与红线

1. **"全局 -30 稳如老狗"是骗局**——只会让体质最好的核心先死；
2. **别同时开全局 Offset 降压和 CO**——双重降压叠加，轻则蓝屏重则开不了机；
3. 别无脑拉满 PPT/TDC/EDC——只会更快撞温度墙，散热才是最终天花板；
4. 更新 BIOS 后 CO 需重新验证（主板保留数值但降压算法可能已变，原来 -20 稳可能刷完 -15 就崩）；
5. PBO Scalar（放宽 FIT 电压保护）Zen4/Zen5 拉高零收益还伤寿命，**99% 的人保持 Auto**；
6. Zen5/9000 系新增 Curve Shaper：按温度×频率两维度分段设曲线（低温区微调保稳、高温区多降保散热），属进阶玩法；
7. 判断调稳的标志不是跑一遍跑分，而是日常真实使用一整周不崩。
