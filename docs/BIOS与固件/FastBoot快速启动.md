# 快速启动 Fast Boot

> **分类**：BIOS 与固件 · 性能优化项
>
> **一句话**：Fast Boot 不提升硬件速度，只跳过开机时重复的硬件自检；系统稳定就开，调试折腾就关。注意它与 Windows 的"快速启动"（Fast Startup）是两套独立功能。

## 原理

开机时很多硬件检测是重复流程（上次开机已验证无误），Fast Boot 直接跳过这些项目，只保留简检。完整开机四阶段：

1. 硬件自检（POST 上电自检）；
2. 设备枚举（盘点全部硬件、统计内存条数、挂载硬盘，设备越多越耗时）；
3. 启动项筛选（按启动顺序检索有系统的分区）；
4. 系统载入。

**Fast Boot 作用于前两个阶段**，典型优化四项：跳过完整内存自检（省约 2~3 秒）、取消 USB 设备全量枚举（仅保留对键盘的基础识别，省约 1~2 秒）、跳过部分板载硬件的重复初始化、缓存正常关机后的硬件配置复用。检测到硬件改动（加装内存/新硬盘）时仍会重新执行必要自检，不会全程乱跳。

## 与 Windows 快速启动的区别

- **BIOS Fast Boot**：固件层面跳过自检；
- **Windows 快速启动（Fast Startup）**：混合关机机制，把系统内核镜像存到硬盘休眠文件，开机直接读镜像。
两者可能互相干扰，遇到开机异常时可到 控制面板 → 电源选项 → 取消勾选"启用快速启动"排查。

## 品牌路径与默认值

华硕在 Boot 菜单；微星在 Settings/高级 → Windows OS Configuration；技嘉在 Boot Configuration。出厂默认各不相同（部分厂商 ROG/TUF 级消费主板默认开启，多数品牌默认关闭）；技嘉/微星多为整体开关、无法自选跳过项；进阶的 Ultra Fast Boot 更激进（连 USB 初始化都跳过），对普通用户实用性偏低，建议用标准版。

## 开关准则

**推荐开启**：日常办公、游戏。
**建议关闭**：高频调试、双系统切换、频繁插拔 USB 外设、需要在开机自检阶段使用 USB 设备（如进 PE）。

口诀：**系统稳定就常开，调试折腾就关闭，调完再开。**

## 常见故障与解法

| 故障 | 解法 |
|---|---|
| 进不了 BIOS | Windows 内跳转：设置 → 恢复 → 高级启动 → 疑难解答 → 高级选项 → UEFI 固件设置（见[BIOS 入门](./BIOS入门进入退出与模式切换.md)）；或清 CMOS |
| USB 键盘开机阶段偶尔失灵 | 频繁用就关 Fast Boot |
| 换新硬件后设备无法识别 | Fast Boot 沿用旧缓存扫不到新硬件——重启几次让固件重新全量检测，或清 CMOS |
