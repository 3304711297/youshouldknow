## 与其他分类的边界

- `系统知识/`、`系统调优与安全/`：系统层设置与优化原则；`软件技巧/` 仅处理应用层客户端偏好，不涉及注册表/BCD/驱动。
- 新增软件技巧时，按“软件名 + 场景”组织，保持单篇可独立阅读。
