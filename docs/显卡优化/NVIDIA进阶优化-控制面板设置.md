# NVIDIA 进阶优化（三）：控制面板设置清单

> **分类**：显卡优化 · NVIDIA
>
> **适用场景**：NVIDIA 控制面板（经典控制面板，非英伟达 App）的 3D 设置、显示设置（更改分辨率 / 桌面缩放 / G-SYNC）、视频颜色三部分的推荐配置。全部以文字清单呈现，照表逐项设置即可。
>
> 设置项均真实存在；推荐值属社区主流的「画质 / 延迟 / 性能」取向，非唯一正确答案。其中「缩放模式」一项按作者勘误修正为**纵横比**（早期版本截图有误），文中有标注。

---

## 一、3D 设置

### 第 1 步：通过预览调整图像设置

选择 **「使用高级 3D 图像」设置**（否则下面的「管理 3D 设置」不生效）。

### 第 2 步：管理 3D 设置 → 全局设置

| # | 设置项 | 推荐值 | 备注 |
| --- | --- | --- | --- |
| 1 | 图形增强 | 关 | 锐化类滤镜，看个人偏好 |
| 2 | CUDA - GPUs | 全部 | — |
| 3 | CUDA - 系统内存回退政策 | 偏好无系统回退 | 深度学习 / 科学计算显存不足时改为「偏好回退」（速度会降） |
| 4 | DSR - 因数 | Off | — |
| 5 | OpenGL GDI 兼容性 | 默认 | — |
| 6 | OpenGL 渲染 GPU | **本机最强 GPU**（笔记本选独显） | 混合显卡平台上「自动选择」可能把 OpenGL 任务路由到核显，显式指定独显更稳妥 |
| 7 | Vulkan / OpenGL 现行方法 | 优先本机（按需，见下注） | 「优先在 DXGI 交换链上分层」会把 Vulkan/OpenGL 程序当作 DX11/12 运行，走 Windows 全屏优化路径——好处是切回桌面不黑屏，坏处是失去真正的全屏独占；「优先本机」则是真全屏独占。按「独占性能」还是「切换体验」自行取舍 |
| 8 | 三重缓冲 | 关闭 | — |
| 9 | 低延时模式 | **开** | 选项实际只有**关 / 开 / 超高**三档。全局选「开」（渲染队列压至 1 帧，无副作用）；「超高」逐帧即时提交、延迟最低但可能损失少量帧数，且 GPU 未跑满时收益甚微甚至略增延迟——仅 GPU 满载的竞技场景值得开。支持 Reflex 的游戏以游戏内 Reflex 开关为准，此项对其不起作用 |
| 10 | 各向异性过滤 | 应用程序控制 | 在游戏内调，建议不低于 8x |
| 11 | 后台应用程序最大帧速率 | 关 | — |
| 12 | 垂直同步 | **关**（前提：G-SYNC 已开启） | 防撕裂交给 G-SYNC，强制开垂直同步反而在帧数顶到刷新率时引入延迟。机制说明：①全局设「关/开」都会覆盖游戏内的垂直同步开关（游戏里开/关不再生效），此为预期行为；②不开 G-SYNC 的普通屏则建议改回「使用 3D 应用程序设置」，把控制权交给游戏；③新电脑或未设置过时此项可能为**空白**，需手动设置 |
| 13 | 多帧采样 AA（MFAA） | 关 | — |
| 14 | 平滑处理 - 模式 / 设置 / 灰度纠正 | 应用程序控制的（或关） | 反锯齿系列子项 |
| 15 | 最大帧速率 | 关 | — |
| 16 | 环境光吸收 | 关 | — |
| 17 | 电源管理模式 | 最高性能优先 | 笔记本见下方「重要提示」 |
| 18 | 监视器技术 | G-SYNC | 不支持的屏选「固定刷新率」；对延迟有极致要求的也可选「固定刷新」——G-SYNC 会略增延迟，但显著减少画面撕裂。FreeSync / Adaptive-Sync 屏经 G-SYNC Compatible 机制同样适用（见 2.3 节说明） |
| 19 | 着色器缓存大小 | 无限制 | 也可给 5GB 上限 |
| 20 | 三线性优化 / 各向异性采样优化 | 关 | 两项是「降采样精度换帧数」的优化：开启会轻微降低三线性 / 各向异性过滤效果。关闭 = 完整采样精度（画质取向），性能代价极小；追求极限帧数的低端卡可开 |
| 21 | 负 LOD 偏移 | 锁定 | 「允许」= 应用可指定负偏移使纹理更锐利，但可能带来闪烁 / 摩尔纹（DLSS 等时间性放大下更明显）；「锁定」= 禁止负偏移，纹理锐度由 AF 正常提供、画面更稳。少数依赖负偏移锐化的老游戏（Doom 3 时代）可按需改「允许」 |
| 22 | 纹理过滤 - 质量 | 质量 | 一站式控制纹理过滤的采样策略，档位从低到高：高性能 → 性能 → **质量** → 高质量。「质量」是画质与性能的主流平衡点；「高质量」强制全程完全三线性，画质提升属边际、开销更大。注意：此项会覆盖 #20 那两项优化的独立开关效果 |
| 23 | 线程优化 | 自动 | 驱动的多线程渲染优化，主要作用于 OpenGL 程序。手动「开」在个别游戏会引发卡顿 / 兼容问题，「自动」交由驱动按程序判断最稳（Blur Busters G-SYNC 101 同样推荐 Auto） |
| 24 | 虚拟现实预渲染帧数等 VR 项 | 跳过 | 仅对 VR 头显应用生效，不用 VR 无需设置；若使用 VR，理论上预渲染帧数 = 1 延迟最低（与低延时模式同一原理） |
| 25 | 首选刷新率 | 最高可用 | 控制显示器实际运行的刷新率档位。「最高可用」强制桌面与游戏始终以显示器最高刷新率运行，并**覆盖游戏的刷新率偏好**——开启 G-SYNC 后此项通常会自动变为「最高可用」（Blur Busters G-SYNC 101 推荐配置），可防止部分游戏把刷新率切到 60Hz 等低档导致 G-SYNC 响应变差；仅在不使用 G-SYNC、或个别游戏需要自行管理刷新率时才改「应用程序控制」 |

> ⚠️ **笔记本重要提示**：「电源管理模式 = 最高性能优先」若设在**全局**，显卡在桌面空闲时也倾向高频运行，可能增加待机功耗与发热、影响续航。更稳妥的做法是全局保持「正常」，仅在具体游戏的**程序设置**里为该游戏单独指定「最高性能优先」。

## 二、显示设置

### 2.1 更改分辨率

在「输出」分组中按以下设置（笔记本本机屏；外接显示器按显示器规格选择）：

| 设置项 | 推荐值 |
| --- | --- |
| 输出颜色格式 | **RGB** |
| 输出颜色深度 | **最高有效值**（如 8bpc；屏与线材支持 10bpc 且有需求时选 10bpc） |
| 输出动态范围 | **完全** |
| 桌面颜色深度 | **最高有效值** |

> 动态范围「完全」= 0-255 全范围输出；「有限」= 16-235（电视标准）。显示器是全范围设备时选「完全」，否则画面发灰。

### 2.2 调整桌面尺寸和位置

**缩放方案按「游戏纵横比」与「显示器纵横比」是否一致选择：**

| 情况 | 缩放模式 | 执行缩放 | 覆盖选项 |
| --- | --- | --- | --- |
| 游戏纵横比 **=** 显示器纵横比 | **纵横比** | **显示器** | — |
| 游戏纵横比 **≠** 显示器纵横比 | **全屏** | **GPU** | 勾选「覆盖由程序设置的缩放模式」 |

**执行缩放设备的选择**（另一条独立规则）：

| 情况 | 选择 |
| --- | --- |
| 高刷电竞屏，或显卡为低端卡 | **显示器**（不占 GPU 资源、延迟更低） |
| 其余情况 | **GPU** |

> ✏️ **勘误**：早期流传截图版本中此页「缩放模式」显示为**全屏**，属图上错误——同纵横比场景正确应选 **「纵横比」**（按比例缩放、不拉伸变形）。
>
> 💡 原理：显示器缩放在显示端完成，不消耗 GPU 资源；GPU 缩放适用于显示器无法自行缩放 / 需要覆盖程序缩放设置的场合（如非同比例拉伸全屏）。

### 2.3 设置 G-SYNC

1. 勾选 **「启用 G-SYNC」**；
2. 「G-SYNC 能够且将会启用的方式」按需选择：
   - **全屏模式**——仅全屏独占游戏生效（推荐，窗口化程序交给系统）；
   - **窗口和全屏模式**——无边界窗口 / 窗口化游戏也生效；**玩窗口化 / 无边框游戏必须勾此项，否则 G-SYNC 对它们完全不生效**；
3. 点击「应用」。

> 屏不支持 G-SYNC / G-SYNC 兼容模式则跳过此页；对延迟有极致要求的也可不开 G-SYNC 用固定刷新——G-SYNC 会略增延迟，但显著减少画面撕裂。
>
> 📌 **FreeSync / Adaptive-Sync 显示器同样适用**：NVIDIA 卡驱动 FreeSync 屏的机制就是「G-SYNC Compatible」（兼容 VESA Adaptive-Sync 标准）。使用流程：显示器 OSD 内先开启 FreeSync → 本页勾选启用（非 NVIDIA 验证名单机型需勾选「为所选显示器型号启用设置」，偶发闪屏属正常）→ 游戏内 `Ctrl+Alt+R` 呼出指示器验证。建议使用 DisplayPort 连接。

#### 防撕裂什么情况下不生效（重点）

G-SYNC 消除画面撕裂的前提是**帧数始终处于 G-SYNC 范围内（低于显示器最大刷新率）**。一旦帧数超过最大刷新率，G-SYNC 即失效——画面重新撕裂（垂直同步关时），或退回普通垂直同步引入缓冲延迟（垂直同步开时）。

**对策：把帧数上限设在略低于最大刷新率的位置**——建议低于刷新率 2～3 帧：144Hz 显示器设 **141～142**、165Hz 设 **162～163**，以此类推。上限设置位置任选其一：游戏内帧数上限 / NVIDIA 控制面板「最大帧速率」（RTSS 亦可）。这是 Blur Busters（G-SYNC 101 系列）给出的标准做法，确保帧数永远不会冲出 G-SYNC 范围。

#### 刷新率设置方法

1. **Windows 设置** → 系统 → 屏幕 → **高级显示设置** → 「选择刷新率」，把刷新率设为显示器支持的**最大值**（如 144Hz）；
2. 若列表中没有目标刷新率：NVIDIA 控制面板 → **更改分辨率** → 自定义分辨率，手动创建对应刷新率的模式。

## 三、视频：调整视频颜色设置

按**是否外接显示器**分两种情况：

**情况 1：外接了显示器**

- 保持默认的 **「通过视频播放器」设置**，**不要**在控制面板里改此项；
- 颜色调整去显示器自身的 **OSD 菜单**里做。

**情况 2：未外接（笔记本本机屏）**

1. 颜色设置方式选择 **「NVIDIA 设置」**（第二项）；
2. 「颜色」页下有亮度 / 对比度 / 伽马与数字视频饱和度滑块，一般保持默认不动；
3. 进入 **「高级」** 选项卡，把 **动态范围** 改为 **「完全」**。

> 动态范围说明：「有限」输出 16-235 的视频电平（电视标准），「完全」输出 0-255 全范围——笔记本屏是全范围显示设备，选「完全」可避免画面发灰。与 2.1「更改分辨率」页的输出动态范围同理，两处都设为「完全」。

## 事实核查记录

| 声明 | 核查结果 |
| --- | --- |
| 上述设置项均存在于 NVIDIA 控制面板 | ✅ 属实：均为控制面板「管理 3D 设置 / 显示 / 视频」中的真实选项（详见官方控制面板帮助） |
| 低延时模式 / 电源管理模式 / G-SYNC / 着色器缓存等推荐值 | 💡 社区主流取向（延迟 / 性能 / 画质权衡），非官方规定；逐项按需取舍 |
| 缩放模式应为「纵横比」 | ✅ 作者勘误：早期截图版本此处的选择有误；完整规则为——纵横比一致时选纵横比+显示器缩放，不一致时选全屏+GPU缩放+勾选覆盖（补充后与社区通用指南一致） |
| 显示器缩放延迟低于 GPU 缩放；高刷屏 / 低端卡选显示器 | 💡 社区通用建议：显示器端缩放不占 GPU 资源，逻辑成立 |
| G-SYNC 略增延迟但减少撕裂；极致延迟可选固定刷新 | ✅ 属实：VRR 同步机制以少量延迟换取无撕裂，与 Blur Busters 等权威测试结论一致 |
| 「优先在 DXGI 交换链上分层」= Vulkan/OpenGL 走 Windows 全屏优化路径，切桌面不黑屏但失去全屏独占 | ✅ 属实：该选项语义与 Windows 全屏优化（DXGI 翻转模型分层）机制描述准确 |
| 动态范围「完全」= 0-255 全范围输出，「有限」= 16-235 | ✅ 属实：NVIDIA 输出范围标准定义；笔记本屏为全范围设备，选完全避免发灰 |
| 更改分辨率页：输出颜色格式 RGB、颜色深度最高有效值、动态范围完全 | ✅ 设置项真实存在；RGB + 全范围为 PC 显示器标准输出组合，10bpc 按屏 / 线材支持取舍 |
| G-SYNC 设置页：启用 G-SYNC，可选全屏模式或窗口和全屏模式 | ✅ 属实：控制面板「设置 G-SYNC」页的真实选项 |
| 低延时模式档位为关 / 开 / 超高（无「高」档） | ✅ 属实：现行驱动控制面板选项；「高」为早期资料误记 |
| 「开」= 队列压至 1 帧；「超高」= 即时提交、延迟最低但可能损失帧数，GPU 未满载时收益甚微甚至略增延迟 | ✅ 属实：Guru3D 与 Blur Busters 实测结论一致 |
| 支持 Reflex 的游戏以游戏内 Reflex 为准，控制面板此项冗余 | ✅ 属实：NVIDIA 官方系统延迟优化指南明确 Reflex 更有效 |
| 垂直同步全局设「关/开」会覆盖游戏内开关；新装系统此项可能为空白，需手动设置 | ✅ 属实：控制面板全局垂直同步会强制覆盖游戏请求 |

| 帧数上限设低于刷新率 2～3 帧（144Hz → 141/142） | ✅ 属实：Blur Busters 标准建议（至少 -2 帧，推荐 -3 帧），确保帧数不冲出 VRR 范围 |
| 刷新率设置：Windows 设置 → 系统 → 屏幕 → 高级显示设置 → 选择刷新率；无目标值时用 NVIDIA 控制面板自定义分辨率创建 | ✅ 属实：均为标准功能路径 |
| 窗口化 / 无边框游戏需在 G-SYNC 页勾选「窗口和全屏模式」，否则不启用 G-SYNC | ✅ 属实：控制面板该选项的既定行为 |
| 三线性 / 各向异性采样优化 = 降采样精度换性能；关闭为画质取向 | ✅ 属实：NVIDIA 官方控制面板帮助对两项优化的定义一致 |
| 负 LOD 偏移「锁定」防止应用指定负偏移、避免闪烁 | ✅ 属实：官方帮助原文——允许时应用可指定负偏移增强锐度，锁定则禁止；画质向教程普遍推荐锁定 |
| 纹理过滤质量档位（高性能→性能→质量→高质量）与「质量」为平衡点 | ✅ 属实：官方帮助档位定义；「高质量」强制完全三线性、收益边际 |
| 线程优化「自动」最稳 | ✅ 属实：Blur Busters G-SYNC 101 推荐配置 |
| 首选刷新率「最高可用」：覆盖游戏刷新率偏好，G-SYNC 启用时自动选中 | ✅ 属实：Blur Busters G-SYNC 101 原文——G-SYNC 启用后自动选择最高可用并覆盖游戏内偏好 |
| 笔记本全局「最高性能优先」影响空闲功耗 | ✅ 属实：最高性能模式抑制降频，待机功耗与发热上升，建议按游戏单独设置 |
| 外接显示器时视频颜色交给播放器 + 显示器 OSD | 💡 作者经验建议：外接显示设备（尤其电视）色彩链路以 OSD 校准为准 |
