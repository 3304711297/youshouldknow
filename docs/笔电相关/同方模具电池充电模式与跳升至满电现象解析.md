# 同方模具电池充电模式与"跳升至 100%"现象解析

> 适用范围：采用同方（Tongfang）模具的电竞笔记本，包括机械革命、 thunderobot、XMG、TUXEDO、Eluktronics 等品牌。不同品牌控制台名称不同（机械革命电竞控制台 / Control Center / TUXEDO Control Center），但底层电池管理逻辑一致。

## 三种电池充电模式

同方模具通过嵌入式控制器（EC，Embedded Controller）固件实现电池充电管理，配合品牌控制台软件提供三种模式：

| 模式 | 充电截止阈值 | Windows 显示 | 适用场景 |
| --- | --- | --- | --- |
| **工作站模式** | 约 85% | 100%（软件映射） | 长期插电、台式机替代，最大程度保护电池 |
| **平衡模式** | 约 91% | 100%（软件映射） | 日常使用，兼顾续航与电池寿命 |
| **长效模式** | 约 98% | 100%（软件映射） | 需要接近满电的移动使用 |

> 上述阈值为通用参考值，具体百分比因型号和 EC 固件版本而异。

## "跳升至 100%"现象：发生了什么？

### 表现

在平衡模式或工作站模式下充电时，电池电量到达一定百分比后充电速度趋近于零，随后在几分钟内**突然跳升至 100%**。这个"跳升点"与所选模式对应：

- 工作站模式 → 在约 **85%** 时跳升至 100%
- 平衡模式 → 在约 **91%** 时跳升至 100%
- 长效模式 → 在约 **98%** 时跳升至 100%

### 原理

这是 **软件层面的映射行为，不是电池物理状态的突变**：

1. EC 固件通过控制充电 IC 来限制电池实际充电上限（例如 85%）
2. 当电池达到该阈值后，EC 停止充电，充电率降为 0
3. 此时 EC 向 Windows 报告的电池百分比**不再基于电池的绝对电量**，而是基于**允许充电范围内相对电量的映射值**
4. Windows 任务栏电池图标因此从实际百分比（如 85%）突然跳变为 100%

简单来说：**Windows 看到的 100% ≠ 电池的物理 100%**。即使在长效模式下，电池也受到了保护，不会被持续微充电循环所消耗。EC 固件在内部始终留有余量。

### 验证方法

如果你希望确认自己的设备确实存在这一行为，可以按以下步骤实测：

1. 安装电池监控软件（需支持记录充电曲线，如 BatteryBar、HWiNFO64 等）
2. 拔出电源，将电池电量用至 **20%** 以下
3. 在控制台中设置电池健康模式为 **工作站模式**
4. 启动电池监控软件，插入电源，充电过程中避免游戏或高负载操作
5. 等待 Windows 显示充电完成（100%）
6. 查看充电曲线，观察是否在约 85% 处出现突然跳升至 100% 的断点

经实测验证，工作站模式下确实在约 85% 处出现了跳升至 100% 的现象，与官方描述一致。

## 电池校准建议

无论使用哪种充电模式，定期校准电池有助于保持电量显示的准确性：

- **频率**：每月至少一次
- **方法**：将电池电量用至 10% 以下，然后插电充满至 100%
- **原理**：校准的是 EC 中电池电量计（fuel gauge）的读数，而非电池化学本身。长期在某一阈值截断充电会导致电量计的基准漂移，定期满充满放可纠正偏差

> ⚠️ 仅在校准时才需要进行深度放电，日常使用中应避免频繁将电量放至 0%。

## 补充说明

- **第三方工具读取实际电量**：HWiNFO64、RWEverything 等工具可直接读取 EC 寄存器中的原始电池百分比，可以看到 Windows 显示 100% 时的实际物理电量
- **切换模式不会立即生效**：从工作站切换到长效模式后，需要等到下一次充电周期才会按新的阈值工作；当前如果已停在 85% 并显示 100%，切换到长效后不会立刻继续充电
- **关机充电同样受控**：EC 固件独立于操作系统运行，关机状态下充电仍会遵循所选模式的阈值限制

## 事实核查记录

| 核查项 | 核查结果 | 说明 |
| --- | --- | --- |
| 同方模具电池充电模式存在三种阈值（85%/91%/98%） | ✅ 属实 | 机械革命电竞控制台提供工作站/平衡/长效三种模式，阈值与搜索结果一致 |
| Windows 显示 100% ≠ 电池物理 100% | ✅ 属实 | EC 固件向 Windows 报告的是相对映射值，非绝对电量；这是同方/多家 OEM 通用的电池管理方案 |
| "跳升至 100%"是软件行为而非电池突变 | ✅ 属实 | 由 EC 固件在充电截止后将百分比映射为 100% 所致，电池本身未发生物理跳变 |
| 每月校准一次电池 | ⚠️ 部分 | 月度校准确实有助于维持电量计精度，但部分现代电池厂商（如 HP）认为仅当电量显示明显不准时才需校准，不必强制每月执行 |
| HWiNFO64 等工具可读取实际物理电量 | ✅ 属实 | 通过读取 EC 原始寄存器可实现，TechPowerUp 论坛和 Reddit 均有用户验证 |
