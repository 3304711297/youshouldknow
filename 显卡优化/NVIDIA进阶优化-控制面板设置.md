# NVIDIA 进阶优化（三）：控制面板设置清单

> **分类**：显卡优化 · NVIDIA
>
> **适用场景**：NVIDIA 控制面板（经典控制面板，非英伟达 App）的 3D 设置、显示设置（更改分辨率 / 桌面缩放 / G-SYNC）、视频颜色三部分的推荐配置。全部以文字清单呈现，照表逐项设置即可。
>
> 设置项均真实存在；推荐值属社区主流的「画质 / 延迟 / 性能」取向，非唯一正确答案。其中「缩放模式」一项按作者勘误修正为**纵横比**（早期版本截图有误），文中有标注。

---

## 一、3D 设置

### 第 1 步：通过预览调整图像设置

选择 **「使用高级 3D 图像」设置**（否则下面的「管理 3D 设置」不生效）。

### 第 2 步：管理 3D 设置 → 全局设置

| # | 设置项 | 推荐值 | 备注 |
| --- | --- | --- | --- |
| 1 | 图形增强 | 关 | 锐化类滤镜，看个人偏好 |
| 2 | CUDA - GPUs | 全部 | — |
| 3 | CUDA - 系统内存回退政策 | 偏好无系统回退 | 深度学习 / 科学计算显存不足时改为「偏好回退」（速度会降） |
| 4 | DSR - 因数 | Off | — |
| 5 | OpenGL GDI 兼容性 | 默认 | — |
| 6 | OpenGL 渲染 GPU | **本机最强 GPU**（笔记本选独显） | 混合显卡平台上「自动选择」可能把 OpenGL 任务路由到核显，显式指定独显更稳妥 |
| 7 | Vulkan / OpenGL 现行方法 | 优先本机（按需，见下注） | 「优先在 DXGI 交换链上分层」会把 Vulkan/OpenGL 程序当作 DX11/12 运行，走 Windows 全屏优化路径——好处是切回桌面不黑屏，坏处是失去真正的全屏独占；「优先本机」则是真全屏独占。按「独占性能」还是「切换体验」自行取舍 |
| 8 | 三重缓冲 | 关闭 | — |
| 9 | 低延时模式 | 高 | — |
| 10 | 各向异性过滤 | 应用程序控制 | 在游戏内调，建议不低于 8x |
| 11 | 后台应用程序最大帧速率 | 关 | — |
| 12 | 垂直同步 | 使用 3D 应用程序设置 | — |
| 13 | 多帧采样 AA（MFAA） | 关 | — |
| 14 | 平滑处理 - 模式 / 设置 / 灰度纠正 | 应用程序控制的（或关） | 反锯齿系列子项 |
| 15 | 最大帧速率 | 关 | — |
| 16 | 环境光吸收 | 关 | — |
| 17 | 电源管理模式 | 最高性能优先 | 笔记本见下方「重要提示」 |
| 18 | 监视器技术 | G-SYNC | 不支持的屏选「固定刷新率」；对延迟有极致要求的也可选「固定刷新」——G-SYNC 会略增延迟，但显著减少画面撕裂 |
| 19 | 着色器缓存大小 | 无限制 | 也可给 5GB 上限 |
| 20 | 三线性优化 / 各向异性采样优化 | 关 | — |
| 21 | 负 LOD 偏移 | 锁定 | — |
| 22 | 纹理过滤 - 质量 | 质量 | — |
| 23 | 线程优化 | 自动 | — |
| 24 | 虚拟现实预渲染帧数等 VR 项 | 跳过 | 未实测；理论上预渲染帧数 = 1 延迟最低 |

> ⚠️ **笔记本重要提示**：「电源管理模式 = 最高性能优先」若设在**全局**，显卡在桌面空闲时也倾向高频运行，可能增加待机功耗与发热、影响续航。更稳妥的做法是全局保持「正常」，仅在具体游戏的**程序设置**里为该游戏单独指定「最高性能优先」。

## 二、显示设置

### 2.1 更改分辨率

在「输出」分组中按以下设置（笔记本本机屏；外接显示器按显示器规格选择）：

| 设置项 | 推荐值 |
| --- | --- |
| 输出颜色格式 | **RGB** |
| 输出颜色深度 | **最高有效值**（如 8bpc；屏与线材支持 10bpc 且有需求时选 10bpc） |
| 输出动态范围 | **完全** |
| 桌面颜色深度 | **最高有效值** |

> 动态范围「完全」= 0-255 全范围输出；「有限」= 16-235（电视标准）。显示器是全范围设备时选「完全」，否则画面发灰。

### 2.2 调整桌面尺寸和位置

**缩放方案按「游戏纵横比」与「显示器纵横比」是否一致选择：**

| 情况 | 缩放模式 | 执行缩放 | 覆盖选项 |
| --- | --- | --- | --- |
| 游戏纵横比 **=** 显示器纵横比 | **纵横比** | **显示器** | — |
| 游戏纵横比 **≠** 显示器纵横比 | **全屏** | **GPU** | 勾选「覆盖由程序设置的缩放模式」 |

**执行缩放设备的选择**（另一条独立规则）：

| 情况 | 选择 |
| --- | --- |
| 高刷电竞屏，或显卡为低端卡 | **显示器**（不占 GPU 资源、延迟更低） |
| 其余情况 | **GPU** |

> ✏️ **勘误**：早期流传截图版本中此页「缩放模式」显示为**全屏**，属图上错误——同纵横比场景正确应选 **「纵横比」**（按比例缩放、不拉伸变形）。
>
> 💡 原理：显示器缩放在显示端完成，不消耗 GPU 资源；GPU 缩放适用于显示器无法自行缩放 / 需要覆盖程序缩放设置的场合（如非同比例拉伸全屏）。

### 2.3 设置 G-SYNC

1. 勾选 **「启用 G-SYNC」**；
2. 「G-SYNC 能够且将会启用的方式」按需选择：
   - **全屏模式**——仅全屏独占游戏生效（推荐，窗口化程序交给系统）；
   - **窗口和全屏模式**——无边界窗口 / 窗口化游戏也生效；
3. 点击「应用」。

> 屏不支持 G-SYNC / G-SYNC 兼容模式则跳过此页；对延迟有极致要求的也可不开 G-SYNC 用固定刷新——G-SYNC 会略增延迟，但显著减少画面撕裂。

## 三、视频：调整视频颜色设置

按**是否外接显示器**分两种情况：

**情况 1：外接了显示器**

- 保持默认的 **「通过视频播放器」设置**，**不要**在控制面板里改此项；
- 颜色调整去显示器自身的 **OSD 菜单**里做。

**情况 2：未外接（笔记本本机屏）**

1. 颜色设置方式选择 **「NVIDIA 设置」**（第二项）；
2. 「颜色」页下有亮度 / 对比度 / 伽马与数字视频饱和度滑块，一般保持默认不动；
3. 进入 **「高级」** 选项卡，把 **动态范围** 改为 **「完全」**。

> 动态范围说明：「有限」输出 16-235 的视频电平（电视标准），「完全」输出 0-255 全范围——笔记本屏是全范围显示设备，选「完全」可避免画面发灰。与 2.1「更改分辨率」页的输出动态范围同理，两处都设为「完全」。

## 事实核查记录

| 声明 | 核查结果 |
| --- | --- |
| 上述设置项均存在于 NVIDIA 控制面板 | ✅ 属实：均为控制面板「管理 3D 设置 / 显示 / 视频」中的真实选项（详见官方控制面板帮助） |
| 低延时模式 / 电源管理模式 / G-SYNC / 着色器缓存等推荐值 | 💡 社区主流取向（延迟 / 性能 / 画质权衡），非官方规定；逐项按需取舍 |
| 缩放模式应为「纵横比」 | ✅ 作者勘误：早期截图版本此处的选择有误；完整规则为——纵横比一致时选纵横比+显示器缩放，不一致时选全屏+GPU缩放+勾选覆盖（补充后与社区通用指南一致） |
| 显示器缩放延迟低于 GPU 缩放；高刷屏 / 低端卡选显示器 | 💡 社区通用建议：显示器端缩放不占 GPU 资源，逻辑成立 |
| G-SYNC 略增延迟但减少撕裂；极致延迟可选固定刷新 | ✅ 属实：VRR 同步机制以少量延迟换取无撕裂，与 Blur Busters 等权威测试结论一致 |
| 「优先在 DXGI 交换链上分层」= Vulkan/OpenGL 走 Windows 全屏优化路径，切桌面不黑屏但失去全屏独占 | ✅ 属实：该选项语义与 Windows 全屏优化（DXGI 翻转模型分层）机制描述准确 |
| 动态范围「完全」= 0-255 全范围输出，「有限」= 16-235 | ✅ 属实：NVIDIA 输出范围标准定义；笔记本屏为全范围设备，选完全避免发灰 |
| 更改分辨率页：输出颜色格式 RGB、颜色深度最高有效值、动态范围完全 | ✅ 设置项真实存在；RGB + 全范围为 PC 显示器标准输出组合，10bpc 按屏 / 线材支持取舍 |
| G-SYNC 设置页：启用 G-SYNC，可选全屏模式或窗口和全屏模式 | ✅ 属实：控制面板「设置 G-SYNC」页的真实选项 |
| 笔记本全局「最高性能优先」影响空闲功耗 | ✅ 属实：最高性能模式抑制降频，待机功耗与发热上升，建议按游戏单独设置 |
| 外接显示器时视频颜色交给播放器 + 显示器 OSD | 💡 作者经验建议：外接显示设备（尤其电视）色彩链路以 OSD 校准为准 |
