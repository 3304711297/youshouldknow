# Windows 优化等级说明

为了避免把所有调整简单理解为“越多越好”，优化项目按影响范围分类。

## 🟢 常规优化

特点：
- 风险较低
- 大多数用户可以尝试
- 通常容易恢复

示例：
- 游戏录制关闭
- 搜索行为调整
- 电源计划调整

## 🟡 环境相关优化

特点：
- 效果取决于硬件和使用方式
- 需要测试

示例：
- HAGS
- MPO
- 内存压缩
- Prefetch

## 🔴 高级实验优化

特点：
- 可能影响系统功能
- 建议提前备份

示例：
- BCD 高级参数
- VBS / Hyper-V 调整
- 安全缓解修改
- Defender 深度修改

## 基本原则

性能优化需要结合：

- CPU 性能
- GPU 驱动
- 内存容量
- 存储设备
- 系统用途

同一个设置在不同设备上的结果可能不同。
