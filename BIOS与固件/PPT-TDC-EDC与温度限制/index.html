    PPT、TDC、EDC 与温度限制¶

    分类：BIOS 与固件 · CPU 性能释放与限制（第二季 EP02）

    风险等级：🟡 中（设置可回滚，但盲目放宽会显著增加发热、功耗与供电负载）。

    一句话：全核满载掉频先查哪面墙先撞顶：PPT（封装功耗 W）、TDC（持续电流 A）、EDC（瞬时电流 A）与温度限制（℃）是 AMD 自动加速的四把软尺；撞墙是算法负反馈「收油门」，不是硬件死机；调节必须先用 HWiNFO 抓取当前值与上限读数，针对性单项放宽，严禁盲抄他人 Motherboard 档数值。

    常见症状与核心认知¶

    在日常使用或调校 AMD 锐龙处理器时，许多玩家经常遭遇以下四大典型痛点：

    1. 渲染/转码十分钟掉频：全核心满载刚启动时全核频率很高，跑了 5~10 分钟后频率明显回落，且再也上不去；
    2. 跑分偏低但温度不高：对比同型号 CPU 跑分低了一大截，但核心温度才 60℃~70℃，散热明明有巨大余量；
    3. 照抄主板档（Motherboard）更烫：跟着网课直接把 PBO Limits 改为 Motherboard 档，跑分几乎没提升，待机与满载温度却大幅恶化；
    4. 9600X / 9700X 的 105W 模式：到底算不算超频？开启后是否影响官方保修？哪些场景能获得实质收益？

    这四个现象本质上都指向同一套底层运行机制：CPU 触发了功耗、电流或温度的限制线（撞墙），正在主动限制频率。

    ┌────────────────────────────────────────────────────────────────────────┐
│                     AMD Precision Boost 自动调频模型                   │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│               ▲ 实时频率 (Effective Clock)                              │
│               │                                                        │
│               │       ┌── 冲高 ──┐                                     │
│               │      /            \   【负反馈收油门】                  │
│               │     /              └─── 撞墙稳定运行 ───►               │
│               └────┴────────────────────────────────────────► 时间     │
│                                                                        │
│  四面墙触发判定：                                                      │
│  ① 封装功耗 (PPT) ──► 达到 Limit ──┐                                   │
│  ② 持续电流 (TDC) ──► 达到 Limit ──┼──► 任一触顶，算法立即降低加速增益  │
│  ③ 瞬时电流 (EDC) ──► 达到 Limit ──┤    （主动回缩频率与电压，绝非崩溃）│
│  ④ 核心温度 (THM) ──► 达到 Limit ──┘                                   │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘

    核心铁律：撞墙是负反馈收油门，不是死机。死机、黑屏或蓝屏多由核心电压不足、内存时序不稳定或触发电源硬件过流关断（OCP）导致；而撞墙是 AMD CPU 内部 SMU（系统管理单元）执行的正常预防性频率管理逻辑，算法侦测到某项电气或热指标贴顶后，平滑回调频率使系统维持在安全阈值内。

    适用范围与 BIOS 选项入口¶

    • 支持架构：AMD 桌面平台 AM4 与 AM5 全系（从 Zen 2 / 锐龙 3000 系列起确立现行 PBO Limits 体系，涵盖 5000、7000、8000G 及 9000 系列）。
    • 笔记本移动端边界：移动端（锐龙 H/HS/HX 系列）由笔记本 OEM 厂商（联想、华硕、机械革命等）通过专属嵌入式控制器（EC）与预置 cTDP 固件锁定，通常不在公开 BIOS 开放自由修改，不直接套用桌面端选项逻辑。
    • BIOS 典型路径：
    • 标准官方路径：Advanced（高级模式）→ AMD Overclocking → Precision Boost Overdrive → PBO Limits（设为 Manual 后显示具体输入框）；
    • 厂商集成路径：微星 OC 页面、华硕 Ai Tweaker / Extreme Tweaker、技嘉 Tweaker、华擎 OC Tweaker。
    • 单位陷阱警示：
    • 部分主板 BIOS（如部分华硕或华擎主板）在 Manual 模式下要求输入的单位是毫瓦（mW）与毫安（mA）而非瓦（W）与安（A）；
    • 例如：设定 142W 功耗需输入 142000，设定 95A 需输入 95000。切勿少输三个零将功耗缩减为 142mW，导致 CPU 锁死在极低频。

    三把电气标尺：PPT / TDC / EDC¶

    AMD PBO Limits 中的三面墙分别管辖着不同的物理维度与电气场景：

    ┌────────┬────────────────────────────┬──────────┬───────────────────────────────┐
│ 参数名 │ 中文全称                   │ 计量单位 │ 管辖场景与物理本质            │
├────────┼────────────────────────────┼──────────┼───────────────────────────────┤
│  PPT   │ Package Power Tracking     │ 瓦 (W)   │ 芯片总封装功耗；管长时间整机  │
│        │ 封装功耗跟踪               │ 或毫瓦   │ 重载下的总电力消耗天花板      │
├────────┼────────────────────────────┼──────────┼───────────────────────────────┤
│  TDC   │ Thermal Design Current     │ 安 (A)   │ 持续稳定电流；管供电与发热累  │
│        │ 热设计电流（持续电流）     │ 或毫安   │ 积约束（名字带热，但不是温度）│
├────────┼────────────────────────────┼──────────┼───────────────────────────────┤
│  EDC   │ Electrical Design Current  │ 安 (A)   │ 瞬时峰值电流；管突发跳变与轻  │
│        │ 电气设计电流（瞬时电流）   │ 或毫安   │ 载冲高频时的供电回路承受力    │
└────────┴────────────────────────────┴──────────┴───────────────────────────────┘

    1. PPT（Package Power Tracking，封装功耗）¶

    • 管什么：限制整个 CPU 处理器插座允许消耗的最大总电功率（包含核心、SOC、内存控制器与 I/O Die 的总和）。
    • 何时撞墙：在渲染（Cinebench、Blender）、视频压片（HandBrake）、编译大型代码库等多核全开、持续高负载场景下，CPU 最先撞到 PPT 上限。

    2. TDC（Thermal Design Current，持续热设计电流）¶

    • 管什么：主板供电模块（VRM）在长期、稳定受热工况下允许供给 CPU 的最大持续直流电流。
    • 名字辨析：TDC 名字里的「Thermal（热）」指的是供电元器件的热积累设计约束，它不是温度读数，更不能当作温度墙。它衡量的是在主板供电散热片达到热平衡前，VRM 持续输出电流的能力。
    • 何时撞墙：在多核心持续烤机测试运行 5~10 分钟后，若供电电流触及该设定，CPU 频率将被遏制。

    3. EDC（Electrical Design Current，瞬时电气设计电流）¶

    • 管什么：主板 VRM 供电在极短时间（毫秒级瞬态）内能够提供的最大峰值电流。
    • 何时撞墙：在游戏加载瞬间、单核突发计算、轻载应用切换、或 CPU 试图冲击最高单核/双核最大睿频时，EDC 最先触顶。若 EDC 设得过紧，CPU 将无法拉出高频峰值；但若盲目拉过高，会导致 VRM 瞬态响应发热增加甚至引起电压下冲（Vdroop）。

    出厂默认值规律与 AM4/AM5 对比¶

    经验公式：出厂功耗墙 ≈ TDP × 1.35¶

    在 AMD 默认规格体系中，处理器的封装功耗限制（PPT）通常并非等于包装盒上印刷的 TDP（热设计功耗），而是遵循一个行业内熟知的经验推算公式：

    $$\text{默认出厂 PPT} \approx \text{标称 TDP} \times 1.353$$

    (注：该经验公式用于理解各档位关系，非 AMD 官方白皮书硬性定律，实际由芯片 AGESA 固件写死)。

    典型档位对照表¶

    处理器 TDP 档位 默认出厂 PPT (W) 典型代表型号 (AM4 / AM5) AM4 典型 TDC / EDC AM5 规格特性
    65W 88W 3600、5600X、7600、9600X、9700X 60A / 90A 需以 HWiNFO 监控读数为准，各主板 BIOS 预设微调
    105W 142W 3700X/3800X、5800X、5900X、7700X 95A / 140A 锐龙 9000 系开放官方 105W 模式（见下文专题）
    120W (X3D) 162W 7800X3D、7950X3D、9800X3D 受 3D V-Cache 耐压保护 固件严格钳位，通常禁用或极度收窄手动放宽
    170W 230W 7900X、7950X 高达 160A / 225A 旗舰双 CCD 满血释放，需 360 水冷以上压制

    AM4 与 AM5 的查询差异¶

    • AM4 平台：各型号的 PPT/TDC/EDC 官方推荐参考基准较为公开统一（如 65W 对应 88W/60A/90A，105W 对应 142W/95A/140A）；
    • AM5 平台：由于 Zen 4 与 Zen 5 引入了更复杂的动态加速算法与主板供电分级，AMD 官方并未发布全系统一的硬性对照总表。用户切勿在网上搜索第三方固定数值照搬，唯一可信的真源是打开 HWiNFO64 查看当前实机汇报的 Current 与 Limit 数值。

    Motherboard 档的本质与防踩坑¶

    许多超频教程推崇将 BIOS 里的 PBO Limits 设为 Motherboard（主板预设档）。这一选项具有鲜明的欺骗性：

    ┌────────────────────────────────────────────────────────────────────────┐
│                        Motherboard 档的本质                            │
├────────────────────────────────────────────────────────────────────────┤
│  同一个选项名称 ──► 在不同品牌、不同型号主板上 ──► 注入完全不同的巨额数值 │
│                                                                        │
│  实机案例对比：                                                        │
│  - 技嘉 X570 AORUS MASTER  ：PPT 1000W / TDC 490A / EDC 630A           │
│  - 微星 MPG X570S CARBON   ：PPT 1000W / TDC 280A / EDC 560A           │
│  - 华硕 ROG 某些高端主板   ：PPT 1200W+ / TDC 540A / EDC 700A+         │
│                                                                        │
│  ⚠️ 认知纠偏：                                                         │
│  1. 填 1000W 不代表 CPU 真能吃 1000W（硅片自身电压架构与物理发热会先限制） │
│  2. 它只是彻底解除了软件层的加速门槛，将限制权完全丢给「温度墙」与「硅耐受度」│
│  3. 劣质散热下开 Motherboard，CPU 会瞬间撞到 95℃ 温度墙，导致积热降频反向变卡 │
└────────────────────────────────────────────────────────────────────────┘

    防踩坑三原则¶

    1. 严禁跨主板抄数值：微星主板用户的 Motherboard 档参数绝对不能填进华硕或技嘉主板的 Manual 里；
    2. 显示 1000W 不等于真实功耗：它只是一个用于解除限制的占位标记，底层仍有 CPU 内部的硬性过流、过温及主板 VRM 保护；
    3. 普通散热勿开 Motherboard 档：百元双塔风冷或 240 水冷开启 Motherboard 档，只会让 CPU 在瞬态冲刺后因积热迅速撞温度墙，频率剧烈波动，性能反而不如出厂默认。

    第四面墙：温度限制（Platform Thermal Throttle Limit）¶

    除了三项电参数外，AMD 体系中存在第四类核心限制——温度限制（PBO Thermal Limit）。

    工作机制¶

    • 位置：通常位于 PBO 菜单中的 Platform Thermal Throttle Limit 或厂商预置的温度分级菜单；
    • 原理：允许用户自定义一个低于出厂默认（如 95℃ / 89℃）的核心最高允许温度（例如设置为 85℃ 或 75℃）；
    • 行为：当核心传感器感知温度贴近设定的温度标尺时，SMU 算法会主动截断频率冲刺，平滑下调工作电压，强制让温度锚定在安全目标以内。

    适用场景与代价权衡¶

    目标场景 推荐设定档位 预期收益 性能代价
    ITX 紧凑小机箱 80℃ ~ 85℃ 极大缓解机箱积热与显卡辅助烘烤 持续全核性能仅下降约 2%~4%，游戏几乎零影响
    单塔风冷 / 静音党 75℃ ~ 80℃ 压制风扇狂暴啸叫，消除满载噪音尖刺 密集长渲染任务时间略微延长
    日常游戏玩家 默认 (Auto) 或 85℃ 保障单核冲频峰值，兼顾长周期芯片寿命 散热器能效最大化释放

    关键警示：盲目调高温度上限绝不等于性能变快。在散热能力没有物理提升的前提下，强行将温度限制从 85℃ 拉到 95℃，CPU 只是在更高的热阻环境下运行，漏电流增加、能效比下降，实际有效频率可能因时钟伸缩（Clock Stretching）反而停滞。

    Ryzen 9000 系（9600X/9700X）官方 105W 模式¶

    Zen 5 架构的锐龙 9600X 与 9700X 出厂默认被设定在极其保守的 65W TDP 档位（默认 PPT 仅 88W），导致多核心持续负载性能受限。AMD 官方随后推出了合法的 105W TDP 预设模式。

    ┌────────────────────────────────────────────────────────────────────────┐
│                   Ryzen 9000 官方 105W 模式核心档案                    │
├────────────────────────────────────────────────────────────────────────┤
│  - 适用型号：仅限 AMD Ryzen 5 9600X 与 Ryzen 7 9700X 两款处理器        │
│  - 固件底座：主板需刷入支持 AGESA 1.2.0.1a / 1.2.0.2 及以上的最新 BIOS │
│  - 开启路径：BIOS 内通常命名为「cTDP to 105W」或「105W TDP Mode」开关   │
│  - 电气变化：PPT 从 88W 提升至 142W，TDC/EDC 联动放宽至 105W 档标准    │
│  - 官方保修：AMD 官方明确确认，在认证 BIOS 中开启 105W 模式保修完全有效 │
│  - 性能收益：微星官方实测 9700X 在 Cinebench R23 多核跑分中，从 20,409  │
│              跃升至 23,153，多核吞吐大幅提升约 13%                     │
│  - 场景边界：增益集中于 Blender/渲染/压片等多核持续重载；轻载与游戏无感 │
└────────────────────────────────────────────────────────────────────────┘

    与手动超频的区别：该模式是 AMD 官方认可的规格档位切换（相当于将原本 65W 的 CPU 恢复为 105W 满血版），不同于用户自己在 Advanced 里随意拉升电压或盲改参数。

    HWiNFO 监控定位四步法¶

    在尝试改动任何 BIOS 设置之前，必须先用科学方法排查出到底是谁在卡你的脖子：

    1. 记录基准 (Baseline)
   └── 打开 HWiNFO64（勾选 Sensors-only），记录静置待机与轻度负载下的温度、有效频率与功耗。

2. 全核拷机 (Stress Test)
   └── 启动 Cinebench R23 / 2024 多核循环测试，或运行 Blender 实际工程渲染，持续跑满至少 10 分钟。

3. 锁定瓶颈 (Identify the Wall)
   └── 观察 HWiNFO 中 CPU [#0] 传感器下的这四项读数：
       - CPU PPT [% of Limit]
       - CPU TDC [% of Limit]
       - CPU EDC [% of Limit]
       - CPU Die (average) / Thermal Limit
       ★ 结论：哪一项的百分比持续贴在 99%~100%（或当前值等于上限），谁就是当前唯一的性能瓶颈！

4. 单项放宽 (Targeted Tuning)
   └── 进 BIOS 仅放宽撞顶的那一项（如 PPT 每次增加 10~20W，或 TDC 增加 10A）；
       改动后重新拷机验证，观察跑分与有效频率是否真实上升，并检查系统事件中是否有 WHEA 错误。

    调节策略与安全回滚红线¶

    针对不同用户群体的调节建议¶

    1. 省心日常党 / 纯游戏玩家：保持全 Auto 即可。出厂默认状态是 AMD 工程师针对能效比、发热与单核加速深度权衡的最佳甜点位。
    2. 渲染 / 压片 / 生产力用户：
    3. 9600X / 9700X 用户优先开启官方 105W 模式；
    4. 其他型号先确保散热规格过关，然后按四步法只放宽触顶参数，严禁三项直接拉满。
    5. ITX / 弱散热 / 静音党：
    6. 保持 PPT/TDC/EDC 默认 Auto，直接调节 Platform Thermal Throttle Limit（设定为 80℃~85℃），简单高效且不损单核。

    激进程度分级（从低到高）¶

    1. 级别 1（安全官方）：官方 105W TDP 模式（仅限特定型号）；
    2. 级别 2（半自动化）：主板 Motherboard 预设档（需强力散热配合）；
    3. 级别 3（精细受控）：手动填入具体 PPT / TDC / EDC 数值（微调单项）；
    4. 级别 4（高风险进阶）：叠加调校 Scalar（标量倍率）、Boost Clock Override（频率正偏置）以及 Curve Optimizer（CO 曲线负压降压）。

    回滚三步法与故障四查¶

    • 回滚第一步：进 BIOS 将 PBO Limits 重新改回 Auto；
    • 回滚第二步：若系统出现不稳定或无法进系统，使用快捷键进 BIOS 执行 Load Optimized Defaults（载入优化默认值）或短接主板 CLRTC/Clear CMOS 跳线；
    • 回滚第三步：进入 Windows 打开「事件查看器」，检查 系统 日志下是否存在来源为 WHEA-Logger（硬件错误）的警告或报错。
    • 故障四查：当放宽限制后系统出现卡顿、黑屏或倒挂时，检查：
    • ① 散热器底座塑料膜是否撕除、硅脂是否压匀；
    • ② 主板 CPU 8-Pin 供电线是否插紧插满；
    • ③ 内存 EXPO / XMP 档位是否在高负载下出现过热报错；
    • ④ 主板 BIOS 与 AGESA 版本是否需要更新以修复已知的微码调度缺陷。

    📋 事实核查记录¶

    待核查声明 / 规则 证据等级 核查结论 事实支撑与边界
    出厂功耗墙大致等于 TDP × 1.35 ✅ 属实 经过验证 65W 对应 88W、105W 对应 142W、170W 对应 230W，系 AMD 官方规格规范比值（1.353x），用于理解各档位关系。
    TDC 是温度墙 ❌ 勘误 完全错误 TDC 是热设计电流（持续直流电流），单位为安培（A）；名字带 Thermal 系指供电模块的热平衡约束，非温度读数。
    不同主板 Motherboard 档数值一致 ❌ 勘误 完全错误 Motherboard 档是主板厂商自定义的宽松上限，各品牌与板型差异极大（如技嘉 490A vs 微星 280A），严禁跨板盲抄。
    撞墙会导致电脑死机或蓝屏 ❌ 勘误 完全错误 撞墙是 AMD SMU 内部的主动负反馈收油门机制，通过平滑降低频率与电压确保稳定运行；死机蓝屏多由掉压或时序错误引发。
    9600X/9700X 官方 105W 模式保修有效 ✅ 属实 官方确认 AMD 官方公开确认，在配套认证主板 BIOS 下开启 105W 模式不影响官方保修；该模式收益集中于持续多核吞吐。
