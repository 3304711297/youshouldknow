    XMP/EXPO 内存认证档科普¶

    分类：内存超频 · 认证档入门

    一句话：XMP/EXPO 不是你自己在超频，是内存厂商帮你超好、测好、打包签字的一键档——不开等于白买高频条。

    关联阅读：本站 DDR5 内存超频时序参数公式速查（手动进阶）、BIOS 分类 DDR5 内存训练与 MCR/PD（开机慢排查）。

    为什么装完机内存只跑 4800¶

    • DDR5 的 JEDEC（制定内存标准的行业组织）基准频率是 4800（DDR4 常见 2133/2666/3200）；主板出厂默认按 JEDEC 基准运行，保证插上任何内存都点亮——这是稳妥，不是缩水。
    • 高频标称（如 DDR5-6000）写在包装上印的"DDR5-6000"那一行字里；没有这一行的就是普条，开不了高频档。
    • 检查是否开启：任务管理器看速度显示 4800 还是 6000；CPU-Z 内存页看 DRAM 频率（显示值是标称的一半，如 DDR5-6000 显示 3000MHz，因 DDR 是双倍速率，正常）。

    名词辨析：四个名字一回事¶

    名字 平台/厂商
    XMP（Extreme Memory Profile） Intel 标准，2007 年推出；DDR4 时代为 XMP 2.0，DDR5 时代为 XMP 3.0（可存多档、支持自定义命名）
    EXPO（Extended Profiles for Overclocking） AMD 的 DDR5 对等标准
    D.O.C.P 华硕部分 AMD 主板的叫法（读 XMP 参数）
    A-XMP 微星部分 AMD 主板的叫法

    参数都是那一组（存在内存条的 SPD 芯片里），别被名字搞混。

    认证档里写了什么¶

    内存条出厂时把一组参数写进 SPD 芯片，通常四样：

    1. 频率：如 DDR5-6000；
    2. 时序：如 32-39-39-80（CL/tRCD/tRP/tRAS，内存访问延迟参数，数字越小越快）；
    3. 电压：如 1.35V（高于 JEDEC 默认 1.1V，高频稳定的保障）；
    4. Gear/分频模式：内存控制器与内存频率的分频关系。

    参数由厂商出厂前测好——所以叫"认证档"，你只管点确认。

    怎么开（通用流程）¶

    1. 开机按 Del/F2 进 BIOS；
    2. 找 Ai Tweaker / OC / Extreme Tweaker 菜单下的 XMP/EXPO/D.O.C.P 选项，选 Profile 1（包装印刷的标称值，厂商保过的"甜点档"）；
    3. F10 保存退出；动手前建议记下当前值或截图留底；

    4. 不稳再试 Profile 2（同频率、时序更松的兼容备份档）。

    5. 华硕 Intel 主板另有 XMP I / XMP II / XMP Tweaked 三档：XMP I（应用频率电压、次要时序交给主板自动训练，多数情况选它就够）、XMP II（完全应用厂商预设所有参数）、XMP Tweaked（厂商参数基础上进一步收紧微调，想折腾再试）。

    6. 笔记本/品牌机多数锁选项，开不了别硬来。
    7. 显存类比同理：插 Intel 平台读 XMP 档，AMD 平台读 EXPO 档。

    稳不稳看三角¶

    频率、时序、内存控制器（IMC）三者共同决定，缺一就降档：

    1. 内存颗粒本身——普条没有高频档；
    2. 主板 BIOS 有开关、供电走线撑得住；
    3. CPU 内存控制器（IMC）体质——IMC 在你 CPU 里，别人稳你不稳很正常。

    分频（Gear）与延迟¶

    • Intel：Gear1 = 控制器与内存同频（延迟最低），Gear2 = 1:2 分频（高频好上、延迟上升）；
    • AMD：UCLK=MCLK 同频（1:1）是甜点；高频 DDR5 常见 1:2——跨分频点那一刻最容易翻车：标称 6000 刚好压在临界点上的条子，降到 5800 往往秒亮，不是条坏了。

    从一键认证档（XMP/EXPO）进阶到手动细调时序¶

    XMP/EXPO 是一键开启的最佳方案，但它主要只锁定了第一时序（CL/tRCD/tRP/tRAS）和主工作电压，其余数十个次要副时序（tRFC、tREFI、tRRD、tFAW、tWTR、tCWL 等）大多交由主板 BIOS 自动训练并以极其保守的规则放宽（这也是华硕提供 XMP I 与 XMP II 区别的根源）。

    如果你开启 XMP/EXPO 稳定后，想要进一步榨干内存性能（如将 DDR5 延迟从 70ns 级压进 55ns 级、大幅提升 1% Low 帧率与竞技游戏防掉帧），核心就是将时序参数从时钟周期换算为绝对物理延迟（纳秒 ns）并手动收紧：

    核心换算公式¶

    $$\text{单时钟周期 } tCK (\text{ns}) = \frac{2000}{\text{等效频率 } (\text{MT/s})}$$

    $$\text{绝对延迟 } (\text{ns}) = \text{时序周期数 } \times tCK = \text{时序周期数 } \times \frac{2000}{\text{等效频率 } (\text{MT/s})}$$

    • 举例：在 DDR5-6000（等效 6000 MT/s）下，$tCK = \frac{2000}{6000} = 0.333\text{ ns}$；
    • $CL 30 = 30 \times 0.333\text{ ns} = 10.0\text{ ns}$；
    • $tRFC 480 = 480 \times 0.333\text{ ns} = 160.0\text{ ns}$（海力士 A-die 颗粒公认黄金甜点）；
    • 主板默认放宽的 $tRFC$ 往往给到 600~800 周期（折合 200~266ns），这就是手动调参仍有 10%~15% 延迟收益的原因。

    进阶调参指引¶

    • 海力士 A-die 颗粒通用公式速查与 AM5 设置 → 见本站 DDR5 内存超频时序参数公式速查；
    • 移动端 / 笔记本海力士新 M-die 实机参数 → 见 i7-12800HX 海力士 M-die 超频参数；
    • 英睿达美光 C8D/M8D1 实机参数 → 见 i7-12800HX 英睿达 C8D-M8D1 超频参数。

    实测收益（视频口径）¶

    • AIDA64：DDR4 开 XMP 后读取带宽 30.6→48.4 GB/s；DDR5 带宽升到约 95 GB/s（涨幅约 27%）；DDR4 延迟 57.5ns→44.6ns（约 -23%）；
    • 游戏：平均帧提升约 5%~8%，1% Low 提升更明显（DDR5 平台可达约 8% 以上），卡顿感明显减少；
    • 生产力（视频剪辑、3D 渲染）直接受益于带宽与延迟。

    什么情况必须开¶

    买了 DDR5-6000 及以上高频条（不开等于白买）；玩高帧率竞技游戏；做视频剪辑/渲染等生产力。入门平台 + 普条开不开差别不大。

    失败排查五步（详见重制版 EP08）¶

    1. 隔离：按恢复默认设置的三种方法清 CMOS 回基础频率，确认机器没坏（内存故障灯/DRAM 黄灯常亮=没过训练）；
    2. 点不亮先降频：7200 降到 6800，或换更松的 Profile 2；
    3. 松时序/小幅加压：加压要谨慎，以稳定为限——猛加压既伤寿命又破保修；
    4. 验证：能进系统≠稳，用内存测试工具跑无错才算门槛，日常用一周不崩才算真稳；
    5. 回默认或降档：文件不丢，CMOS 只改参数。

    三个常见误区¶

    1. 开 XMP 会烧内存/不保修？ 不会——厂商写进 SPD 的参数在保修范围内；Intel 与 AMD 官方态度：使用 XMP/EXPO 配置不影响保修。只有手动突破范围加压才可能涉及判定；
    2. XMP 和手动超频一样危险？ 完全不是一个级别——XMP 是厂商预设的保守方案，手动调时序加压才是激进超频；
    3. 开机变慢了？ DDR5 正常现象：内存训练 30~60 秒；可用 MCR+PD 组合提速（见 DDR5 内存训练与 MCR/PD）。

    装机前提醒：先确认内存插对插槽组成双通道（通常 2/4 槽，以说明书为准）——插错位置，频率再高也白搭。
